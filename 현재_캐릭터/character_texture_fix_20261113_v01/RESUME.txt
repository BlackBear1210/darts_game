현재 작업
- Tripo 유료 다듬기 대신 Blender에서 기존 리깅 모델의 부분 색칠 오류 수정.
- 입력: Downloads/tripo_convert_954d3209-6b1c-413f-9c5c-acc1b483b08f.zip
- 원본 ZIP, 추출한 원본 텍스처, 게임에 적용된 캐릭터는 변경하지 않았다.
- 눈썹 아래 흰색 잔여물, 셔츠에 묻은 피부색, 팔 안쪽에 묻은 보라색을 보정했다.
- 얼굴 모양/체형/각/UV/뼈대/가중치는 보존했다.
- 겨드랑이의 찝히는 형태·변형은 색칠과 별개로 남아 있다.

주의
- 마지막 눈썹 주변 피부색 조정 후 GLB·FBX 재열기 검사는 통과했다.
- 최신 렌더가 생성된 직후 사용자가 중단을 요청했으므로, 최신 이미지의 최종 육안 검토는 재개 후 진행한다.
- 이 파일은 사용자 승인 완료본으로 간주하지 않는다.
- character_texture_fixed_package.zip, result_face_front.png, result_left_underarm.png는 현재 최신 파일로 다시 묶어 저장했다.
- 게임 적용이나 Git 커밋·푸시는 아직 하지 않았다.

검증
- repair_verification.json : 정점·토폴로지·UV·가중치·뼈대 해시 일치.
- export_verification.json : GLB/FBX 각각 모델 1개, 뼈 65개, 삼각형 94,928개, 전체 정점에 가중치 존재, 크기 오차 2e-7 미만.
- GLB를 Blender에 가져오면 Icosphere라는 뼈 표시용 도우미가 추가된다. 실제 GLB 메시가 하나 더 있는 것은 아니며, 검사에서 이 도우미만 제외했다.
- texture_verification.json : GLB 내부 최종 기본 색상 맵 PNG 일치, 원본 픽셀 98% 이상 유지.

재현
- fix_materials.py : 원본을 불러와 3D 위치와 기존 색으로 제한한 재질 보정을 UV에 부분 베이크.
- finish_native.py : 편집본 뷰 설정.
- export_and_verify.py : GLB/FBX 내보내기, 다시 열기 검사 및 렌더.
- finalize_all.py : finish_native + export_and_verify 순서 실행.
- package_result.py : ZIP 묶기 및 GLB 내장 이미지 확인.
- Blender 5.2 CLI 사용. 현재 라이브 Blender 연결은 되지 않았다.
- GLB 내보내기는 기본 실행에서 임시 이미지 쓰기 권한 오류가 발생하여 허용된 확대 권한 실행으로 성공했다.
