중간 시안 캐릭터 4방향 이미지

01_front.png : 정면
02_left.png  : 왼쪽을 바라보는 측면
03_back.png  : 후면
04_right.png : 오른쪽을 바라보는 측면

tripo_four_views_png.zip : 위 4장의 개별 PNG만 포함

첨부받은 승인 시안과 새 정면 앵커를 참조해 built-in image_gen으로 생성한 4방향 참고 이미지다.
각 PNG에는 글자와 테두리를 넣지 않았다. 개별 생성 이미지이므로 실제 단일 3D 모델에서
촬영한 정확한 투영도는 아니다. 각 파일의 실제 해상도는 image_manifest.json에서 확인할 수 있다.
생성 프롬프트는 같은 이름의 *_prompt.txt에 저장했다.
