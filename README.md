# Darts Game

Godot 4.6.3으로 만드는 2~4인 멀티플레이 다트 파티게임.

Godot 프로젝트는 [`다트-/project.godot`](다트-/project.godot)에 있다.
저장소를 받은 뒤 Godot에서 해당 파일을 가져오고 F5로 실행한다.

- [실행과 검증 방법](다트-/README.md)
- [첫 번째 아이디어의 조작과 규칙](다트-/docs/first_idea.md)
- [멀티플레이 연결 안내](다트-/docs/multiplayer.md)
- [코드 구조](다트-/docs/architecture.md)
- [코드 작성 기준](AGENTS.md)
