수정 사항
- 앞머리 윤곽을 다시 구성하고 뒤통수와 연결된 단일 헤어 메시로 제작.
- 이마, 광대, 턱 비율 및 얼굴 앞뒤 면 조정.
- 코를 별도 부착물에서 얼굴과 이어진 메시로 변경하고 코끝 폭과 돌출 조정.
- 눈 두께와 음영, 귀 크기/방향, 목 기울기와 밑부분 폭 수정.
- 옷깃의 겹친 면 수정, 소매 끝과 신발 모서리 및 바지 무릎 면 조정.

모든 결과 이미지는 Blender에서 실제 메시를 렌더한 것입니다.
비교 이미지는 해당 렌더와 원본의 크기를 맞춰 나란히 배치한 것입니다.
머리카락, 몸, 상의, 바지, 신발은 컬렉션으로 분리되어 있습니다.
원본 도안은 편집용 blend 파일에도 포함되어 있습니다.

현재 상태
외형 검토용 모델이며 애니메이션 리깅과 제작용 UV는 아직 없습니다.
원본과 픽셀 단위로 동일한 재현은 아니며 헤어 면의 흐름과 귀/측면 윤곽 등에 차이가 남아 있습니다.
팀 공유 안내
- 최신 공유 버전은 이 V08 폴더입니다. V01~V07 폴더는 정리하여 삭제했습니다.
- Blender 5.2에서 위 편집용 원본 3개를 열어 확인했습니다.
- 외부 연결 라이브러리는 없고 참고 이미지는 blend 내부에 포함되어 있습니다.
- 일부 이미지의 원래 경로에 v07이 남아 있어도 내장 이미지를 사용하므로 v07 폴더는 필요하지 않습니다.
- ZIP은 중복 배포본, .blend1은 자동 백업, .log는 작업 로그이며 Git 공유 대상에서 제외합니다.
- Python 스크립트와 비교 이미지는 제작 과정 참고용입니다. 모델 확인은 위 blend 파일을 직접 여세요.
