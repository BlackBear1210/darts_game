## 생각(v3, 2026-11-28)

캐릭터 = **인형**(민머리 + 얼굴 조각) + **헤어 부품**(덩어리). 다른 게임의 모듈식 캐릭터(Synty POLYGON·Sidekick — 머리·헤어·눈썹·수염을
따로 갈아 끼움)와 제페토 헤어 가이드(헤어는 닫힌 덩어리 · 두피를 빈틈없이 덮기 · 마스크 속으로 파고들지 않기)를 따랐다.

- v2(11-27)는 승인 모델 머리에 조각된 곱슬을 눌러 민머리를 만들었다 → 두피가 울룩불룩, 온은 뒷머리·윗머리가 따로 놀았다.
- v3는 승인 머리를 **새로 뜬 각진 로우폴리 머리**(약 2천 2백 면)로 통째로 바꾼다. 눈·코·입·턱 자리와 선은 승인 얼굴 그대로.
- 헤어는 어느 캐릭터에나 끼운다(꾸미기 칸 "헤어"). 기본 캐릭터 + 헤어 0 = 승인 모델 그대로(인형을 쓰지 않는다).
- v4(11-28 시안 피드백 "뒤통수 → 목이 뭉툭 · 헤어가 낮아 볼륨이 없다 · 면이 일정해 직사각형으로 나뉘어 보인다"):
  - 귀 뒤·목덜미를 깎았다 — 두개골 밑선(뒤 1.524 m · 귀 밑 1.498 m) 아래는 잘라 내고 목 이음새를 위로 뽑은 목기둥과 합친다.
  - 헤어 두께: 옆 1~1.5 cm · 위 2.5~3.5 cm(예전 0.5~1.7 cm). 꼭대기 상한 1.80 → **1.835 m**(1.805 m 위는 절반으로 누름).
  - 불규칙한 면: 모자 점을 벽돌처럼 엇갈리고 옆·위아래·두께를 흔든다 · 다발 결(lanes)과 홈 · 이마선 끝 톱니 · 튜브 단면 들쭉날쭉(jit)·비틀기(twist) · 대각선 무작위.
  - 짧은 헤어 뒤 머리선을 1.49~1.51 m 로 올렸다(깎은 목기둥 위 끝). 헤어 바탕은 두피 둘레 최댓값(`head_r_hull`) 위에 얹는다.
- v5(11-28 저녁 피드백 "민머리를 옆에서 보면 뒤통수가 너무 크다" → "크기만 줄인 것 같다 · 두개골이 아닌 인형 머리처럼 원형으로 ·
  점 1개 말고 10개쯤 더 · 위에서 봤을 때 둥글게"):
  - 귀 줄 평면(z = `BACK_ZC` −0.05) 뒤를 **둥근 인형 뒤통수**로 새로 그린다(`_round_back`). 높이마다 가로 단면이 타원 호
    (옆 반지름 = 그 높이 원래 반폭 → 귀 줄에서 꺾임 없이 이어짐 · 뒤 반지름 `_back_depth`). 옆에서 본 뒤통수도 타원 호:
    가장 튀어나온 곳 y 1.60 에서 z 0.08(v4 0.115), 위로 0.175 m 가면 정수리, 아래로 0.11 m 가면 목 쪽으로 공처럼 말려 들어가 목기둥과 합친다.
  - 뒤쪽 세로줄을 한쪽 3 → 8개(`AZ_HALF` 102·112·…·170, 약 10° 간격)로 늘렸다 — 인형 머리 2,238 → 2,618 면(온 2,602).
  - 헤어 두께 전체 ×1.15(`HAIR_VOL`) + 뒤통수 자리(방위 110° 밖)에 5 mm 더(`_vol`, 스포츠 컷은 2.5 mm).
- v6(11-28 밤 피드백 "점이 너무 많아 주름처럼 자글자글" → 면 줄이기 시안을 보고 "승인 모델 원본으로 따라가자 · 많지만 들어가고 나오는
  면으로 각을 만들어 이목구비를 구성한다 · 좌우 대칭 · 면도 승인 모델처럼 · 우리 캐릭터는 매끈하게 하지 않으니 각이 얼굴을 구성하는 게 포인트"):
  - **면 줄이기(QEM)는 버렸다** — 승인 얼굴의 큰 판(눈썹뼈·눈두덩·상자 코·광대 판·턱)이 무너져 더 이상해졌다.
  - 얼굴(K) = 승인 머리 면에서 머리카락 면을 뺀 것을 **그대로** 쓰고, 매끈한 영역 선(`_region_f`: 이마 위 곡선 · 옆 경계
    `TEMPLE_AZ/SIDE_AZ/NECK_AZ` · 목 이음새에서 3D 거리 `SEAM_GAP` 1 cm)으로 자른 뒤 x = 0 에서 잘라 오른쪽 반을 거울로 붙인다(정확한 대칭).
    목 이음새 간격을 높이(y)로 재면 이음새보다 낮은 턱 밑면이 통째로 잘렸다 → 이음새 꺾은선까지 3D 거리로 잰다.
  - 두피(D) = 나머지(이마선 위 · 옆머리 · 귀 뒤 · 뒤통수 · 뒷목). 방향 공간 4.5° 점 + 구면 들로네(경계 복원 · 접힌 경계는 잇기용 방향만 편다),
    높이 = v5 둥근 인형 머리(RAD) + 경계 차이(가린 푸아송) + **경계 기울기 잇기**(경계 11° 안 두피 점이 승인 면이 나가던 기울기를 이어받는다).
  - 귀 = 승인 귀 **전체**(귀 상자 `EAR_BOX` 안 머리카락 아닌 면 중 테두리와 이어진 덩어리 — 승인 모델은 바깥 테두리만 '귀' 색이고
    귓바퀴 안·귀 뒷면은 살 색이라 테두리만 쓰면 얇은 C 고리만 남았다). 두피 위에 따로 얹고 뿌리 2고리만 두피 속으로 당긴다.
  - 음영 = 승인 모델과 같은 이웃 면 넓이 가중 평균 법선(각은 면의 기하가 만든다). 머리 하나 약 2만 6천 면 · 정점 1만 5천(나눠 쓰는 정점 —
    자료 `heads` 에 `i`(삼각형 번호) · `w`(정점마다 뼈 가중치를 베낄 승인 정점) 키가 붙는다).
  - 눈썹: 승인 눈썹뼈가 각진 판이라 제어점 사이에서 면이 눈썹보다 앞으로 나와 군데군데 묻혔다 → 제어점 3배 · 위/가운데/아래 중 가장 앞 면 기준.
  - 헤어 `bun`(올림머리, 솜 기본): 뒤로 넘겨 캐릭터 왼쪽 뒤 · 귀 높이에 낮게 틀어 올린 똬리(감아 올린 굵은 다발 + 속 덩이 + 머리끈 `tie`)
    + 가르마(왼쪽 −36°)에서 오른쪽으로 넘긴 앞 볼륨. 단발(bob)은 꾸미기에서 고를 수 있다.
  - 개발 원본: 스크래치 `appr_head.py`(얼굴 K · 두피 · 귀 조립)를 `hair_geo.py` 의 "v6" 절에 붙여 넣어 한 파일로 둔다.

## 무엇이 자료에 들어 있나

| 자료 | 내용 |
|---|---|
| `heads` | 캐릭터(base·jun·som·on)마다 인형 머리. 정점·법선·색 키(0 피부·1 흰자·2 눈동자·3 입·4 눈썹)·이음새 원래 정점 번호 · v6: `i` 삼각형 번호 · `w` 뼈 가중치 원본 정점 |
| `head_rigid_src` | 이음새가 아닌 인형 정점이 뼈 가중치를 베끼는 승인 머리 정점(정수리) |
| `parts` (kind `hair`) | 헤어 부품 6종: wavy(기본 인형) · spiky(준) · bob(솜) · curls(온) · crew · pony(머리끈 `tie` 색) |
| `parts` (kind `extra`) | 옷 조각: 소맷단 · 깃 · 바짓단 · 허리 탭 · 신발 고리 · 솜 속눈썹 |

얼굴형(턱·볼·코), 두툼한 손, 피부·머리·눈썹·입 색, 체형은 `character_looks.gd`의 표(`FACE`, `HAND_THICKEN`, `LOOKS`)에 있다.
**얼굴형 `FACE` 를 고치면 `hair_geo.py` 의 `FACE` 도 같이 고치고 자료를 다시 만든다**(인형 머리에 구워져 있다 · 목 앞은 게임이 같은 식으로 민다).

## 다시 만드는 순서 (Git Bash)

준비: Godot 4.6.3 콘솔 실행 파일, Python 3 + numpy(+ 사진 묶음은 Pillow), 저장소 `darts_game/다트-`. `run.sh` 맨 위 `G`(Godot 자리)를 내 컴퓨터에 맞춘다.

```bash
# 1) 승인 모델 머리·몸 정점과 텍스처 색 뽑기 (약 9MB, 승인 모델이 바뀌었을 때만)
./run.sh zz_export_head "C:\...\work\mesh.json"
# 2) 인형 머리·헤어·옷 조각 모양 만들기 → work/geo.json (약 6초)
python hair_geo.py work
# 3) geo.json → 저장소 art/characters/character_look_data.res
./run.sh zz_convert_geo "C:\...\work\geo.json"
# 4) 확인 사진 (창 모드 필수 — 창 없이 돌리면 사진이 안 찍힌다)
./run.sh --window zz_char_review turn "C:\...\out" base base:1 jun som on      # 12방향 + 위에서 3컷 (base = 승인 모델)
./run.sh --window zz_char_review bald "C:\...\out" base:1 jun som on           # 헤어 뗀 인형
./run.sh --window zz_char_review turn "C:\...\out" jun:4 som:6 on:0:3 som:3:1:1  # 헤어 바꿔 끼우기 · 모자 · 안경
python sheet15.py out out/sheet.png 200 base base_h1 jun som on                # 12방향 + 위 3컷 한 장
./run.sh --window zz_char_review mix "C:\...\out" jun:5 som:6 on:0:3            # 조합표용 7컷만(빠르다)
./run.sh --window zz_char_review close "C:\...\out" jun som on jun:hair som:hair   # v6 얼굴 가까이 0~180° + 아래(민머리 / ":hair" = 기본 헤어)
```
렌더 창이 뒤로 가면 느려져 Godot 600초 제한에 걸릴 수 있다 → `turn` 은 한 번에 캐릭터 2~3명, `mix` 는 4명 이하로 나눠 돌린다.

`run.sh`는 도구를 Godot 프로젝트 `tests/`에 잠깐 복사해 돌리고, 끝나면 복사본과 `.uid`를 지운다(게임 폴더에 남지 않는다).

## hair_geo.py 구조

1. **두피 지도**(1~2절) — 승인 머리에서 머리카락(텍스처가 어둡고 따뜻한 정점)이 아닌 살의 방향별 반지름으로 매끈한 두피를 잰다. 헤어 위치 계산의 바탕.
2. **인형 머리**(`새 인형 머리` 절)
   - 눈금: 방위 36칸(`AZ_HALF`, 얼굴 앞이 촘촘 · v5 부터 뒤쪽도 약 10°) × 고도 줄(`FACE_ROWS`: 턱 밑 −58 · 턱 −50 · 입 −43 · 코밑 −38 · 코 · 광대 · 눈 · 눈썹 13 · 이마 · 정수리).
   - 머리 가운데 `HC`에서 쏜 광선이 승인 얼굴에 닿은 거리 = 반지름. 머리카락 자리는 두피 지도, 눈·코·귀 자리는 이웃으로 메운다. 좌우 대칭.
   - 손질: 두개골 고르기 · 뒷머리 아래 S 곡선(두개골 → 목, 풍선처럼 처지지 않게) · 관자 채우기 · 볼·귀 둘레 고르기 ·
     **귀 뒤·목덜미 깎기**(v4: 방위 84° 밖, 두개골 밑판 `NAPE_RIM` 아래를 자르고 목기둥 `_ray_neck` 과 합침) · 눈자리 파기 ·
     **둥근 인형 뒤통수**(v5 `_round_back`: 같은 방향 광선이 "타원 뒤통수 ∪ 목기둥" 경계에 닿는 거리를 이분법으로 찾아 반지름 표를 다시 씀).
   - 네모는 더 평평한 대각선으로 나눈다(면이 깨끗한 판으로 읽히게). 목 이음새는 승인 머리 아래 테두리(118점)를 **테두리를 걸은 순서**로 지퍼처럼 잇고, 띠의 감는 방향은 껍데기에서 이웃으로 번져 맞춘다(각도 순서로 이으면 턱 뒤에서 꼬여 틈·뒤집힌 면이 생겼다).
   - 조각: 눈알(20면체 2단) · 눈동자 · 코(쐐기, `FACE` 코 길이·폭) · 귀(앞은 머리에 붙고 뒤가 2.2 cm 벌어진 콩 모양) · 입(막대, 얼굴 면 2.4 mm 앞) · 눈썹(`BROWS` 제어점, 이마 면에 얹음).
   - 음영: 면마다 정점 셋. 법선 = 면 55 % + 40° 안 이웃 평균(`shaded`). 이음새 띠만 부드럽게.
3. **헤어 부품** — `cap_solid`(이마선 `*_lim` 부터 정수리까지 두께 있는 닫힌 모자, 이마선 가장자리는 두피 속으로 접힘) + `tube` 다발 + `ico` 곱슬 덩이. `head_r` 가 인형 머리 표면이라 헤어가 인형에 딱 붙는다. 1.805 m 위는 절반으로 눌러 1.835 m 를 넘지 않는다.
   - `cap_solid(..., lanes, lane_amp, tip_deg, scatter, edge_thin)`: 다발 결 수·결 높낮이·이마선 톱니 깊이(°)·점 흔들기(칸)·끝 두께 배.
   - `tube(..., jit, twist, seed)`: 단면 점 들쭉날쭉·고리 비틀기. 단발 `hang_lock` 은 네 마디로 부풀었다 끝이 안으로 말리고 옆으로 휜다.
4. **옷 조각**(v1 그대로) — 소맷단·깃·바짓단·탭·고리·속눈썹.

## 자주 걸리는 것

- 승인 모델을 다시 만들면 머리 정점 수가 달라진다 → 게임은 인형 머리를 건너뛰고(승인 머리 그대로) 경고를 낸다. 1)부터 다시.
- 인형 머리 색은 정점 색(sRGB)이고 셰이더(`character_skin.gdshaderinc` `vertex_paint`)가 몸과 같은 빛으로 칠한다. 목 면(`all_skin`)은 단색 피부 → 목 이음새에 밝기 띠가 없다.
- 모자를 쓰면 `_under_hat()`이 1.72~1.785 m 헤어를 승인 모델 옛 머리 바깥선(`HAT_FIT_OUTLINE`)에 맞춘다(좁으면 부풀리고 v4 처럼 넓으면 좁힌다) — 모자 5종이 승인 모델 머리에 맞춰져 있어서. 헤어 모양을 크게 바꾸면 모자 사진을 꼭 다시 본다.
- 목덜미를 깎은 뒤로 헤어 머리선을 1.47 m 아래로 내리면 가는 목 한가운데에서 끝나 뒤에서 어두운 구멍처럼 보인다.
- 헤어 머리선 높이 → 고도는 **깎기 전** 매끈한 머리(`RAD_PRE`, `el_at_height_smooth`)로 잰다. 깎은 머리의 두개골 밑판은 거의 평평해서
  높이 몇 mm 차이에 고도가 크게 튀어, 머리선이 판을 가로지르는 귀 뒤(방위 ±130° 둘레)에 찢어진 틈이 생겼다.
