# 캐릭터 3안(준·솜·온) 머리·눈썹 자료 만들기 — 2026-11-27 v2

게임 안 캐릭터 조립은 저장소 `다트-/art/characters/character_looks.gd`가 합니다.
이 폴더는 그 조립이 읽는 **모양 자료**(`art/characters/character_look_data.res`)를 다시 만드는 도구입니다.
Godot 프로젝트(`다트-`) 밖에 두는 이유: 게임 실행에 필요 없는 개발 도구라서 게임 용량·내보내기에 섞지 않으려고.

## 무엇이 자료에 들어 있나

| 자료 | 내용 |
|---|---|
| `moved_index` / `moved_position` | 승인 모델 머리 텍스처에 그려진 옛 곱슬머리 정점을 **두피 안**으로 눌러 넣은 자리 |
| `parts` (kind `hair`) | 캐릭터별 새 머리(낮은 다각형). 준 = 짧은 옆머리 + 삐죽 다발 · 솜 = 턱선 단발 + 옆으로 넘긴 앞머리 · 온 = 짙은 페이드(`fade` 색) + 정수리 곱슬 |
| `parts` (kind `extra`) | 입체 눈썹(`brow`) · 소맷단 · 깃 · 바짓단 · 허리 탭 · 신발 고리 · 솜 속눈썹 |

얼굴형(턱·볼·코), 두툼한 손, 피부·머리 색, 체형은 자료가 아니라 `character_looks.gd`의 표(`FACE`, `HAND_THICKEN`, `LOOKS`)와 함수에 있습니다 — 숫자만 고치면 됩니다.

## 다시 만드는 순서 (Git Bash)

준비: Godot 4.6.3 콘솔 실행 파일, Python 3 + numpy, 저장소 `darts_game/다트-`. `run.sh` 맨 위 `G`(Godot 자리)를 내 컴퓨터에 맞춥니다.

```bash
# 1) 승인 모델 머리·몸 정점과 텍스처 색 뽑기 (약 9MB, 승인 모델이 바뀌었을 때만)
./run.sh zz_export_head "C:\...\work\mesh.json"
# 2) 머리·눈썹 모양 만들기 → work/geo.json
python hair_geo.py work
# 3) geo.json → 저장소 art/characters/character_look_data.res
./run.sh zz_convert_geo "C:\...\work\geo.json"
# 4) 확인 사진 (창 모드 필수 — 창 없이 돌리면 사진이 안 찍힌다)
./run.sh --window zz_char_review turn  "C:\...\out" base jun som on   # 12방향 전신·얼굴
./run.sh --window zz_char_review hands "C:\...\out" base jun som on   # 오른손 8방향
./run.sh --window zz_char_review hats  "C:\...\out"                   # 모자 6종 × 3방향
./run.sh --window zz_char_review glasses "C:\...\out"                 # 안경 3종
python turn_sheet.py out face out/face.png base jun som on            # 한 장 묶음(face·body·hand)
```

`run.sh`는 도구를 Godot 프로젝트 `tests/`에 잠깐 복사해 돌리고, 끝나면 복사본과 `.uid`를 지웁니다(게임 폴더에 남지 않습니다).

## hair_geo.py 구조

1. **머리카락 정점 고르기** — 텍스처 색(어둡고 따뜻함)으로. 얼굴 앞(눈썹·입술선·눈동자)은 뺀다.
2. **두피 지도** — 머리카락이 아닌 살 정점(이마·관자·뒤통수 아래)의 방향별 반지름(4°칸)을 재고, 머리카락 칸은 이웃 평균을 400번 되풀이해 매끈하게 채운다. **귀는 빼서** 새 머리 밖으로 나오게 한다.
   - v1(2026-11-26)은 작은 타원체로 눌러서 이마 위가 7 cm 움푹 꺼졌다 → 이마에 들쭉날쭉한 옛 머리선이 보였다.
3. **옛 곱슬머리 눌러 넣기** — 머리카락 정점을 두피 지도 3 mm 안으로.
4. **새 머리** — `shell()`: 방위마다 이마선 높이(`*_lim`)에서 정수리까지 줄을 나눈 껍데기 + 첫 줄 아래 한 줄은 머리 속으로 접어 넣는다.
   - 준: `tuft()` 다각뿔 16개(앞은 앞·위로, 정수리는 위·뒤로 쏠림).
   - 솜: `som_hang()` — 귀 높이 아래는 수직으로 떨어지고(목을 따라 감기지 않게), 귀 둘레보다 8 mm 밖(귀가 뚫고 나오지 않게), 끝단은 기둥마다 0.7 cm 들쭉날쭉.
   - 온: 얇은 페이드 껍데기(`fade` 색) + 두툼한 정수리 껍데기 + 작은 곱슬 덩이 53개(20면 — 80면이면 정점이 두 배라 줄였다).
   - 준·온은 키 180 cm 규칙으로 1.775 m 위를 절반으로 눌러 1.80 m 를 넘지 않는다.
5. **입체 눈썹** — `brow()`: 안쪽→바깥 제어점(가운데 x, 높이, 세로 두께, 앞으로 나온 깊이). 이마 표면(살 정점 중 가장 앞)에서 앞으로 6~12 mm, 튀어나온 눈알(앞 z −0.227)보다 앞에 놓인다.
   - 준 = 굵고 곧게(안쪽 끝이 낮다) · 솜 = 가늘고 둥근 아치 · 온 = 짧고 두툼한 각진 눈썹.
6. **덧붙이는 조각**(v1 그대로) — 소맷단·깃·바짓단·탭·고리·속눈썹.

## 자주 걸리는 것

- 승인 모델을 다시 만들면 머리 정점 수가 달라진다 → 게임은 옛 머리 눌러 넣기를 건너뛰고 경고를 낸다. 1)부터 다시.
- 그림 머리카락·눈썹은 셰이더(`character_skin.gdshaderinc`)가 **전부 살색**으로 지운다. 입술선(높이 1.56 m 아래 · 얼굴 앞)만 남는다. 그래서 새 머리가 덮지 않는 곳은 매끈한 살(두피)로 보인다.
- 모자를 쓰면 `character_looks.gd` `_under_hat()`이 1.72~1.785 m 머리를 승인 모델 옛 머리 바깥선(`HAT_FIT_OUTLINE`)까지 부풀린다 — 모자 5종이 승인 모델 머리에 맞춰져 있어서. 머리 모양을 크게 바꾸면 모자 사진(`hats`)을 꼭 다시 본다.
- 바탕화면 `darty_캐릭터_디자인/게임안_캐릭터_2026-11-27/`에 12방향·모자·손·1인칭 사진이 있다.
