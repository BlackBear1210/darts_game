# 카드 피드백·손 연출·NPC 종료 (2026-11-11)

- 작업자 / 브랜치: Codex / dev_1. 미커밋, 푸시 보류.
- 요청: 제안 2~6번 구현. 1번 힘 증가+특수 다트 등의 조합 판정은 팀 논의 후로 보류.

## 구현

- `game/match/match_cards.gd`: 중첩되지 않는 power/triple/cover/drowsy/spin/split의 중복 사용을 서버에서 거절한다. 손패·꺼내 든 카드가 보존된다. 숫자 섞기의 재사용과 연산·바람·무거운 다트의 기존 중첩은 유지한다. 봇도 중복 카드를 피하며, 이미 꺼낸 사이에 다른 사람이 같은 효과를 걸었다면 내려놓는다.
- 같은 파일의 `card_effects.details`에 실제 유효한 효과 이름·지속 범위·중첩 횟수를 담는다. 기존 Dictionary 스냅샷 경로로 다른 참가자에게 전달한다.
- `ui/lounge_hud.gd`: 점수판 아래 활성 효과 표시, 비행 중 `이번 비행` 안내, 중복 카드 패널 경고·Q/E 다른 카드 선택 안내. HUD 130%에서 하단 안내가 밀리는 위치를 보정했다.
- 졸림 강도는 F5/F6 공용 0.3 → 0.18. 조준점에 정적인 금색 모서리와 안내를 표시한다. 조준 오차를 예고하며 중력·다른 카드까지 반영한 탄착점 예측이 아니다. 화면 효과 OFF는 예고를 숨기지만 서버 오차 판정은 유지한다.
- `art/characters/first_person_arm.gd`: 손 크기 0.52, 엄지·검지 끝 사이에 자루를 배치, 나머지 손가락을 덜 움켜쥐며 발사 후에는 편다. 원본 GLB·3인칭 스켈레톤은 수정하지 않는다.
- `game/game.gd`: 충전 이동 거리를 줄이고 손목 회전·손가락 놓기를 연결했다. 움직임 줄이기에서는 충전 떨림 제거·이동/반동 30%. `HAND_CHARGE_OFFSET`을 미리보기와 공유한다.
- `art/pub/npc_idle.gd`, `pub_service.gd`: skeleton_updated에서 자기 노드와 스켈레톤·시가·연기의 트리 생존을 검사해 장면 종료 중 global_transform 오류를 막는다.
