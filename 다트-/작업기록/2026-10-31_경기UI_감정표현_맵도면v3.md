# 경기 UI · 봇 손 카드 · F 카드 쓰기 · T 감정표현 · 맵 도면 v3 (2026-10-31 저녁~밤)

- 상태: 자동 검증 PASS(아래), **미커밋**. 사람 손맛·실제 여러 PC 화면은 미검증.
- 출발점: 같은 날 오후 작업([앉은 시점·엿보기·마시기·유리 파편](2026-10-31_앉은시점_엿보기_마시기_유리파편.md)) 위에서 했다.

## 사용자 요청

1. 싱글에서 봇 손에 카드가 안 들려 있다.
2. 카드를 아직 Enter 로 쓴다 → F 로 빠르게 쓰고 키 배치를 간단하게.
3. 테이블에는 상대 카드·내 카드가 전부 앞면으로.
4. 다트 라운드 → 다음 카드 충전 라운드 표시(예전에 화면 아래에 있던 것)가 왜 사라졌는지 확인하고, 줄어드는 초를 화면 위 가운데에, 그 위에 "다트 라운드 → 다음 카드 라운드" 를 크게. 나중에 설정에서 UI 위치를 옮기게 할 것(이번엔 노드만 묶어 둠).
5. 예전에 만든 이모티콘이 사라졌다 → T 로 골라 마이크 없이도 쓰게.
6. 디테일(Pipes 류 게임처럼 만지면 반응하는 물건·귀엽고 자연스러운 움직임) · 고도에서 직접 실행해 깨지거나 튀어나온 곳 고치기.
7. 다른 작업자가 보낸 에셋 묶음을 재고 맵 도면을 새로 — 다트 던지는 공간·테이블 공간 구성, 비슷한 에셋이 있으면 기존 오브젝트 교체, 상호작용 다시 정의.

## 라운드 표시가 사라졌던 이유

◆ 카드 / ● 다트 라운드 칸 표시는 **F6 카드 라운드 시연**(`game/card_round/ui/round_tracker.gd`)에만 있었다.
10-30 F5 로비·HUD 를 새로 만들 때(`ui/lounge_hud.gd`) 이 표시를 옮기지 않아, F5 경기에는 왼쪽 위 단계 카드에 초만 남았다.
지운 게 아니라 처음부터 F5 에 연결된 적이 없었다 → `ui/round_banner.gd` 로 F5 경기 상태(`MatchState`)를 직접 읽어 다시 만들었다.

## 함정

- 방 기본 테마가 오락실일 수 있다 → 펍 가구를 보는 시험은 `options.theme_id = 0`.
- 에셋 메시는 재질이 메시에 붙어 있어(`material_override` 아님) `StaticBatch` 가 안 묶는다 → 색·흔들림이 산다. 도형(종)을 흔들려면 `NO_BATCH_NAMES` 에 넣어야 한다.
- 새 가구 자리 상수를 바꾸면 `layout_signature` 가 바뀐다 → `pub_builder.gd` 다시 실행(안 하면 `test_game_look` 실패).
- 새 스크립트 `.uid`(held_cards · round_banner · emotes · render_match_ui · render_map_tour · rg_poly_catalog · rg_poly_baker)는 에디터가 다시 훑으면 생긴다 — 스크립트와 같은 커밋에. `docs/2026-10-31_DARTY_맵도면_v3.png` 의 `.import` 도 같다.
- 굽기 시트(`--sheet`) 칸 글자가 작다(창 크기 배율 때문). 측정값(`sizes.tsv`)은 정확.
