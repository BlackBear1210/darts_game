## 먼저 잰 것 — 감으로 고치지 않으려고

같은 조준 묶음(사람 손떨림을 흉내낸 400발, 과녁 반지름 기준 흔들림 0.22)을 **카드 없이 / 카드 걸고** 던져
평균 점수를 비교했다. 카드마다 5번씩 새로 걸어 평균을 냈다(바람 방향·점수 고정 칸처럼 쓸 때마다 무작위인 카드가 있다).
확인 스크립트는 `.godot/check_balance.gd`·`check_sweep.gd`(Git 제외).

**카드 없음 = 평균 13.0점**

### 고치기 전에 드러난 것

| 카드 | 잰 값 | 문제 |
|---|---|---|
| 점수 랜덤 변경 | **+44%** | 방해 카드인데 **상대 점수를 올려 주고 있었다**. 링 배수(싱글·더블·트리플)까지 1~3 무작위로 바꿔 **가장 넓은 싱글 링이 평균 ×2** 가 됐다. |
| 무게 증가 | **+2%** | 아래로 0.45 밀어도 점수가 안 깎인다 — 과녁은 위아래로 대칭이라 **그냥 밀기만 해서는** 다른 칸으로 옮겨 갈 뿐이다. 밀려서 **판 밖으로 나가야** 깎인다. |
| 점수 고정 | −4% (뽑기마다 10.4~15.5) | 고정 값이 1~20 무작위라 **높은 값이 걸리면 상대를 도와줬다**. |
| 봉쇄 구역 | −2% | 시너지로 2~3칸까지 늘던 것이 1칸만 남았다. |

밀림 폭을 따로 쓸어 봤다(카드 없이 조준점만 밀어서):

```
drop 0.45 → +2%    0.60 → -6%    0.75 → -19%    0.90 → -45%    1.05 → -70%
push 0.32 → -17%   0.50 → -16%   0.65 → -20%    0.80 → -32%    1.00 → -60%
```

## 고친 것 — 네 가지만

| 카드 | 바꾼 값 | 결과 |
|---|---|---|
| **무게 증가** | `drop` 0.45 → **0.8** | +2% → **−19%** |
| **점수 랜덤 변경** | 링 배수는 **건드리지 않는다**. 불만 낮춘다(25~60 → 15~45, 10~40 → 5~25) | +44% → **−9%** |
| **점수 고정** | 고정 값 1~20 → **1~6** (카드 글도 같이) | −4%(10.4~15.5) → **−16%**(9.4~12.3) |
| **봉쇄 구역** | 1칸 → **3칸**(고른 칸 + 양옆, 예전 3인 시너지 단계를 기본으로) | −2% → **−11%** |
| **먹물 얼룩** | 5칸 → **8칸**(예전 2인 단계를 기본으로) | 점수에는 영향 없음(가리기만 한다) |

## 안 고친 것과 이유

- **바람(−10%) · 셔터(−52%) · 피자 분리(−60%) · 세로/가로 분리(−41/−42%)**: 이미 충분히 세다.
  특히 바람은 시너지 시절 2인 값(0.48)도 재 보니 −16% 로 지금(0.32, −10%)과 큰 차이가 없었다 — 잃은 게 거의 없다.
- **숫자 섞기(+1%) · 과녁 회전(+2%) · 어지러움(0%) · 먹물 얼룩(0%)**: 이 방법으로는 0 이 나오는 게 정상이다.
  **무작위로 던지는 가상 플레이어를 괴롭히지 못할 뿐, 숫자를 보고 노리는 사람에게는 효과가 있다.** 수치를 올리면 엉뚱하게 세진다.
- **과녁 크기 변화(+2%)**: 작아지거나(×0.7) 커지는(×1.35) 도박 카드라 평균이 0 근처인 게 의도다.
- **조작 반전 · 정전 · 망원경 · 딸꾹질 · 유체이탈**: 사람의 조준·화면을 건드리는 카드라 이 방법으로 못 잰다.

## 센 카드끼리의 격차 — 팀 확정 필요

고친 뒤에도 **−60%(피자 분리)부터 −7%(과녁 이동)까지** 폭이 크다. 어느 쪽에 맞출지는 기획 결정이라 건드리지 않았다.
참고로 자기 강화 **특수 다트는 +115%**(세 발 중 최고점)로 모든 카드 중 가장 세다.
