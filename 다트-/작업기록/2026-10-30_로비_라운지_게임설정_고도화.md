## 요청과 적용 범위

사용자는 F5의 예시 자동 실행을 로비부터 시작하는 게임으로 바꾸고 디자인·개발·기획 연결을 함께 요청했다. 첨부된 이전 문서의 예시 수치와 미정 아이디어는 확정 요구로 취급하지 않았다. 운영 로그인, 음주 전달 연출, 병 벌점, 카드 밸런스는 요청에 나온 미정 사항을 유지한다. 기존 F6 카드 시연과 기획 흐름 시연은 보존한다.

이번 구현은 로컬/LAN 플레이 가능한 고도화 시제품이다. 작업 시작 원본의 SHA256과 변경 파일 목록을 비교하여 원본에서 다른 작업자가 바꾼 파일을 덮어쓰지 않도록 반영한다. Git 커밋·푸시는 수행하지 않는다.

## 구현 확인 사항

- 로비 문구: **다트를 던져라. 판을 뒤집어라.** 다트 포인터는 버튼 클릭 시 짧게 날고 빈 곳 클릭 시 1.5초 숨는다. 버튼의 기본 클릭·키보드 동작은 유지한다.
- 싱글 1인+봇 0~3명, 멀티 현재 2~4명. 비공개 초대 코드와 선택 비밀번호. 초대 문자열에 IP/포트가 있어 별도 서버 없이 주소를 채운다.
- 비밀번호 원문과 검증 해시는 공개 방 스냅샷에 넣지 않는다. 랜덤 도전값에 응답하는 해시로 확인한다. 이는 LAN 시제품 입장 제어이며 암호화된 운영 계정 인증이나 강한 인터넷 보안 프로토콜을 뜻하지 않는다.
- 맵의 원형 테이블: E 착석 → Enter 참여 → 양팔 들기·인원 체크 → 전원 자동 시작. 규칙 변경·재경기 시 사람의 참여가 초기화된다.
- 캐주얼/파티/클래식 프리셋과 접는 설명. 3종 승리 조건, 라운드·카드·시간·테마·음주 강도·공간 효과음. 경기 도중 라운드 상한·다트/카드 제한 시간·특수 카드 확률도 변경 가능하다. 현재 턴은 보존하고 다음 턴·다음 보충부터 적용한다. 테마·승리 방식 등 나머지는 대기실에서 바꾼다. 실제 멀티 검사로 다음 카드 턴 12초·다트 턴 15초가 적용되고 진행 중 테마 변경은 거부되는 것을 확인했다.
- 개발자 기능은 Debug + --developer + 로컬 서버 방장에 한정. 카드 카탈로그의 포함/제외와 가중치 변경이며 새로운 카드 정의를 작성하는 툴은 아니다.
- 카드 7장 보충, 카드 턴당 한 장 또는 패스, 선택 후 1.2초 사용 대기, 상대 턴의 ×0 대응, 다트 중 사용 금지. 기존 계산식과 목표/카운트다운 계산을 재사용한다.
- 소품은 방장이 거리·시선·소유권·요청 간격을 검사한다. 병은 F 음료, 우클릭 투척, 실제 레이와 캐릭터 캡슐 적중 스턴. 공·큐는 운반만. 음주 스택 숫자는 플레이어 HUD에 표시하지 않는다.
- 기본 병 적중 1초 스턴, 빗나감 2초 회수 대기, 적중은 스턴 시간만큼 회수 대기 증가. 숨은 취기는 한 스택당 약 35초 감소. 모두 밸런스 초안이며 점수 벌점은 미구현/팀 논의 대상이다.
- 주크박스 버튼과 다이얼은 누구나 조작 가능. 게임 내 자체 음악 루프, YouTube 선택 시 각자의 외부 브라우저 공식 플레이어로 전환한다.

## 명확히 남은 범위

1. 운영용 로그인/계정·공개 방 검색·인터넷 NAT 중계·초대 코드 중앙 조회는 미연결. 현재 초대는 직접 주소 접속이다.
2. YouTube는 게임 안 내장 재생이 아닌 외부 공식 플레이어다. 실제 온라인 영상 재생, 국가/영상별 임베드 제한, 다른 PC에서의 사용은 미검증. 플레이헤드까지 맞추는 정밀 동기화는 없다.
3. F6 카드 시연의 셔플/한 장씩 배부 애니메이션, 보상 카드·골드·벌칙 원판·목소리 변조 등 모든 연출을 F5에 이식하지는 않았다. F5에는 핵심 카드 사용과 점수/방해 규칙을 연결했다. 3갈래 다트 효과는 후보 궤적 중 좋은 판정을 쓰며 화면에는 한 발을 표시한다.
4. 네온 테마는 기존 펍 배치에 색·조명·간판·오락기 장식을 더한 1차 테마다. 독립 맵 구조와 최종 아트는 추후 작업한다. 바텐더가 직접 음료를 배달하는 연출, 당구 플레이는 미정/보류다.
5. 키 설정은 E/R·F/G와 감도, UI 배율은 경기 HUD가 대상이다. 모든 키의 자유 리매핑과 전체 메뉴 배율은 후속 확장이다.
6. 사람의 조작감/멀미/음향 품질, 다른 실제 PC 간 LAN/인터넷, 배포 빌드와 운영 서버, 브라우저 로그인·음악은 수동 확인이 남는다.
