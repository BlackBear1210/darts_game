# CARD_PLAN 28종 구현 — 2026-11-12

사용자가 제공한 바탕 화면의 `CARD_PLAN.md`와 후속 답변을 반영했다. 문서의 제안 수치는 사용자가 먼저 구현하도록 승인했다. 시너지·추가 조합 보상은 보류한다.

## 승인받은 기본 규칙

- 연산 카드는 누가 쓰든 현재 투척자에게 적용한다. 카드를 사용한 순서대로 연산하며 음수·소수 한 자리를 허용한다. 각 단계에서 0.1점 단위 반올림. 미스는 연산을 소비하고 0점을 유지하되 구역 지목의 실패 감점은 적용한다.
- 목표 점수는 기존 도달 조건, 카운트다운은 기존 정확히 0/버스트를 유지하면서 0.1점 정수 단위로 계산한다. 음수 득점은 카운트다운 잔여 점수를 늘린다.
- 점수 고정: 내·외불을 포함한 82개 물리 구역 중 무작위 5~20개를 1~20 중 같은 값으로 고정한다. 현재 라운드 끝까지 공유 과녁에 남는다. 다른 과녁 값 카드와 움직임은 차례가 끝나면 복원한다.
- 재도전: 플레이어별 경기당 1회, 자기 차례에 사용하고 바로 다음에 추가 3발 차례를 받는다. 승리가 확정되면 추가 차례를 시작하지 않는다.
- 구역 지목: 선택한 물리 섹터 명중 +15, 실패는 그 섹터의 현재 싱글 점수만큼 감점. 중복 숫자가 가능하므로 숫자 값이 아닌 20개 위치 중 하나를 선택한다.
- 몸 받기 보상: 카드 사용 후 현재 라운드의 이후 피격마다 +30. 기본 15점과 임시 카드 보상을 없앴다. 카드 없이 맞으면 이번 라운드 동안 약한 어지러움. 투척자의 기존 벌(취기·감도·난시 중 무작위 하나+음성 변조)은 이번 차례까지 유지한다.

- 구역 선택은 카드 패널에서 Z/X, 사용은 기존 F. 투척 전 선택 카드 4종은 비행 중 사용하지 못한다. 금색 영역이 선택 위치를 표시한다.
- +10·×2·−20은 네트워크 카드 번호를 밀지 않도록 비활성 자리만 남겼다. 지급·사용·설정 목록에서 제외. 안정 다트는 기존 활성 목록에 없다.
- 5분류 추첨 가중치 1.2/1/1/1/0.6. 특수 포함 기본 확률 12.5%; 기존 프리셋의 특수 포함/제외 설정과 경기당 무효 1장 제한은 유지한다.
- 특수 다트는 발사 때 30/30/30/10%로 3발/가로2발/세로2발/기본+무작위1발을 뽑는다. 각 다트의 실제 비행을 생성하고 점수를 합산한다. 비행 재계산에도 같은 패턴을 유지한다.
- 큰 다트는 정규화 반지름 0.06 원 안 4096개 고정 표본의 면적 우세 구역으로 판정한다. 표본 동률은 방장 난수로 고른다. 해석적 면적 적분이 아닌 근사 계산이다.
- 투척 속도 ×1.3, 무게 낙하 0.45, 바람 좌우 ±0.32. 졸림 공용 오차는 기획 제안값 ±0.3으로 변경했고 눈이 감길 때 짧게 흐려진다.
- 좌우/상하 분리는 최대 0.18·열림 1.5초, 과녁 왕복 이동은 진폭 0.25·주기 3초. 조작 반전은 좌우/상하/전체 40/40/20%.
- F5는 방장이 카드·난수·선택·채점을 확정하고 스냅샷과 비행 이벤트로 전송한다. F6도 공용 규칙·새 과녁 표현·추가 차례·점수판을 연결하고 예전 +15/보상 카드 설정을 제거했으며 기존 시연의 카드 턴 구조는 유지했다.
- 소수·음수 점수는 UI·순위·경기 스냅샷·백엔드 저장까지 유지한다. 이전 SQLite INTEGER 열도 SQLite의 숫자 저장 특성상 소수를 저장할 수 있다.
