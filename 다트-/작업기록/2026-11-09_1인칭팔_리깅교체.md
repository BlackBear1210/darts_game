# 1인칭 팔을 리깅 캐릭터 오른팔로 바꿨다 (2026-11-09)

- 작업자 / 브랜치: AI / `dev_1`
- 요청: "게임 시점에서 플레이어 팔이 아직 예전 프로토타입으로 보여 바꿔줘."

## 무엇이 남아 있었나

몸(2026-11-06)·펍 NPC·바텐더(2026-11-08)는 리깅 캐릭터로 바뀌었는데 **1인칭 손만** 옛 도형 모델이었다:
`character_factory.create_hand()` — 구(벙어리장갑)·막대(소매) 조합에 자리 색 소매. 실제 경기에 남은 마지막 옛 프로토타입 아트였다.

## 어떻게 바꿨나

새 파일 `art/characters/first_person_arm.gd`. 선수 몸과 **같은 리깅 캐릭터**(`rigged/player_character.tscn`)를 1인칭 팔로 쓴다.

- **팔만 보이기**: 캐릭터는 스킨드 메시 9조각이고 조각마다 매달린 뼈가 다르다(이번에 측정해 주석에 적어 뒀다).
  오른팔에 필요한 `tripo_part_0`(몸통 + 오른팔)·`tripo_part_4`(오른손)만 켜고 나머지(머리·다리·왼팔·발)는 끈다.
  목록에 없는 조각은 전부 끄므로 모델을 다시 구워 조각이 늘어나도 얼굴이 화면에 튀지 않는다.
- **몸통 숨기기**: 뼈를 접거나 메시를 자르지 않는다. 손을 화면 앞에 맞추면 몸통이 카메라 **뒤**로 가 근평면에서 잘린다.
- **자세**: `Dart_Throw` 모션의 겨누기 시각(`CharacterMotion.AIM_TIME`) 한 장면만 꺼내 고정하고 재생을 멈춘다.
  충전·반동 연출(`GameView._animate_hand`)은 **건드리지 않았다** — 손맛 코드 그대로, 보이는 모양만 바뀐다.
- **다트 쥐기**: 손의 `Socket_Dart_R`(GLB 에 들어 있는 소켓)을 다트 자루 자리에 맞춘다.
  다트 회전 숫자를 베껴 적지 않고 씬의 `HeldDart.transform` 을 `dart_grip` 으로 받아 쓴다.

바꾼 곳은 F5 경기(`game/game.gd _equip_hand`)와 F6 카드 라운드 시연(`game/card_round/card_round.gd`) 두 곳이다.
둘 다 `Camera/Hand` 자리가 같아(0.2, -0.14, -0.55) 같은 팔이 그대로 맞는다.

## 맞추면서 알게 된 것(숫자의 이유)

- `BoneAttachment3D`(hand_R)의 `global_transform` 은 **다음 프레임에야** 따라온다. `_ready` 에서 그냥 읽으면 쉬는 자세라
  팔이 엉뚱한 곳에 붙는다 → 뼈 자세(`get_bone_global_pose`)에서 직접 만든다.
- 다트 실측(`game/dart/dart.tscn`): 촉 0~0.02 · **자루 0.02~0.07** · 대 0.07~0.14 · 깃 0.10~0.17 (원점 = 촉, +Z 로 뻗는다).
  `GRIP_ALONG_SHAFT = 0.045` 는 자루 가운데다.
- 캐릭터가 만화 비율이라 **주먹 폭이 약 0.15m** 로 길이 0.17m 짜리 다트를 통째로 삼켰다 → `HAND_SCALE = 0.6`
  (1인칭 뷰모델에서 흔히 쓰는 축소. 3인칭 몸은 그대로다).
- 다트 축을 정면으로 보는 시점이라 깃(카메라 쪽 끝)이 손을 가린다 → `GRIP_OFFSET` 으로 주먹을 축 아래로 내려
  **깃 밑에서 자루를 쥔** 모양으로 만들었다(옛 손의 "주먹이 다트 몸통을 아래에서 쥔다"와 같은 구도).

경기 전체를 띄우는 `render_first_idea` 는 이 PC(소프트웨어 렌더러)에서 10분 넘게 걸려 각도를 맞출 수 없었다.

## 미검증 / 남은 작업

- **사람이 F5 로 직접 던져 보지는 않았다.** 충전·발사 중 팔이 움직이는 느낌은 화면 캡처로만 봤다.
- 이 PC 는 소프트웨어 렌더러(Microsoft Basic Render Driver)라 `tests/render_first_idea.gd` 가
  `score == 50`(0.9초 안에 다트가 꽂혀야 하는 단언)에서 실패한다. 실제 GPU 에서 다시 확인이 필요하다.
  팔은 `Camera/Hand` 아래 **충돌 없는 시각 메시**뿐이라 투척 판정에 닿지 않는다(다트 레이는 마스크 1, 몸 판정은 `actors` 만 본다).
- **F6 가리키는 손(`card_round/flow/gestures.gd`)은 아직 옛 도형 손이다.** 그 코드가 옛 손의 내부 노드(`Mitten`)를 찾아
  손가락 막대를 덧붙이고 위치·각도도 그 모델에 맞춰 둬서, 바꾸려면 F6 에서 다시 맞춰야 한다.
  리깅 캐릭터에 `Point_R` 모션이 있으므로 `first_person_arm.gd` 에 자세를 고를 수 있게 하면 같은 방식으로 바꿀 수 있다.
- 팔 크기(`HAND_SCALE` 0.6)·쥐는 자리는 **눈으로 맞춘 값**이다. 팀이 보고 조정할 수 있다 — `render_fp_arm.gd` 로 바로 확인된다.
