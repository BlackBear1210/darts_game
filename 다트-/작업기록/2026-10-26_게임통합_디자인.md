# 2026-10-26 디자인 외형을 F5 실제 경기에 연결 (팀 피드백 빌드)

- 작업자 / 브랜치: 김도형(디자인) + Claude Code / `dev_1` (미커밋)
- 요청: 디자인한 테이블·맵(펍)·다트판·캐릭터가 실제 F5 게임에 하나도 안 나온다. `art/` 쇼케이스와 바탕화면 `DARTY_프로젝트` 디자인을 실제 게임에 합치고, 게임처럼 보이는지 눈으로 확인하고, Godot에서 오류 없이 도는지 확인. 팀원 피드백용. 코드에 설명 주석. 3D가 처음이라 필요한 디자인 프롬프트와 다음 할 일을 `DARTY_프로젝트`에 자세히.

## 원칙

- **숫자 원본은 팀 코드.** 과녁 위치·크기(2.5배, 높이 2.9m)·투척선·제한 벽·테이블·자리 좌표는 `game/table/table.gd`(TableView) 상수 그대로다. 디자인은 그 값을 읽어 그림만 만든다.
- **충돌과 그림을 나눈다.** TableView = 충돌 상자만(메시 없음), 펍 씬 = 그림만(충돌 없음). 그래서 외형을 바꿔도 이동·투척 판정·네트워크는 그대로다.
- 이동 속도·충돌 캡슐·눈높이·채점·네트워크 메시지는 바꾸지 않았다. 몸짓은 각 화면에서 이미 동기화되는 값(위치·자세·속도·조준 중 여부)으로 만든다.

## 작업 내용

### 펍 방
- `art/pub/game_room_builder.gd`(새 파일): TableView 상수를 읽어 경기용 펍을 조립 → 생성물 `art/pub/pub_game.tscn`. 묶음: Shell(바닥·벽·천장·창문·문), BoardWall(과녁 캐비닛·칠판 2개·스포트), Lane(레인 매트·투척선·로프·기둥), TableAndSeats(원탁·자리별 색 스툴·색 매트·모양 표식), Obstacles(스툴 3개), Bar(카운터·탭·병 선반·바텐더), Decor(화분·술통·액자·주크박스·조명 스위치), Lights.
- 방 루트에 `layout_signature` 메타 → TableView 상수를 바꾸고 재생성을 잊으면 F5 시작 때 경고, `test_game_look` 실패.
- `game/table/table.gd`: 예전 회색 상자 그림을 지우고 충돌만(StaticBody3D 13개: 바닥·벽 4·천장·제한 벽·테이블·바·주크박스·스툴 3). 바·주크박스 충돌 상자 추가(`BAR_BOX`, `JUKEBOX_BOX`). 화면이 있을 때만 `StaticBatch`로 정적 메시를 묶는다. `set_chalk_scores()`로 칠판에 점수.
- `art/pub/pub_parts.gd`(새 파일): 스툴·원탁·펜던트·벽등·기둥·로프·창문·화분·병 선반 부품과 공용 재질 → 쇼케이스 펍과 경기 펍이 같은 부품을 쓴다.

### 다트판
- `art/board_art.gd`(새 파일): 칸·링·숫자·뒤판 그림. 링 비율은 팀 `BoardLayout`. 쇼케이스·F5 공용.
- `game/board/board.gd`: `show_layout()`이 `BoardArt.build()`로 다시 그린다 → 카드로 숫자 배치가 바뀌어도 그림이 따라간다. `board.tscn`은 스크립트 루트만.

### 캐릭터
- `art/player_look.gd`(새 파일, PlayerLook): 자리별 색·모양(●▲■◆)·캐릭터 씬·이름 약속표. 이름표·매트·스툴·HUD·칠판·다트 깃이 모두 이 표를 본다.
- `art/characters/character_rig.gd`(새 파일, CharacterRig): 피벗(LegL/LegR/Body/ArmL/ArmR/Neck)을 돌려 서기 숨쉬기·걷기·숙이기·앉기·점프·조준(오른팔 듦)·던지기·눈 깜빡임.
- `game/player/player.gd`: 캡슐·원기둥 대신 자리 캐릭터(`Model`, 180° 회전). 자리별 렌더 레이어 유지(자기 몸은 자기 카메라에서 안 보임). 이름표에 자리 표식·외곽선, 앉으면 머리와 겹치지 않게 높이 조정.
- `art/characters/character_factory.gd`: 바텐더 NPC 추가, 1인칭 손 재설계(벙어리장갑 손·자리 색 소매, 그림자 끔). 생성물 `chr_bartender.tscn` 추가, 기존 4명 재생성.

### 다트·손·HUD
- `game/dart/dart.tscn`/`dart.gd`: 은 촉·금 몸통·검정 샤프트·자리 색 깃(`paint()`), 꽂히는 동안 `Visual`만 1→2.2배(과녁 2.5배와 맞춤, 채점 무관).
- `game/game.gd`/`game.tscn`: 1인칭 손을 자리 색 손으로 교체(`_equip_hand`), 손 다트 각도, 조준 중 몸짓(`aiming`), 던질 때 몸짓·깃 색, 칠판 점수(`_chalk_text`). 예전 빈 방 조명(WorldEnvironment·KeyLight·WarmLight)은 펍 조명으로 대체.
- `ui/pub_theme.gd`(새 파일, PubTheme): HUD·대기실 공용 색(먹녹색·크림·놋쇠). `ui/game_hud.gd`: 점수 판넬·자리 표식, `lobby/lobby.gd`: 테마·배경색.

### 시험
- `tests/test_game_look.gd`(새, headless): 방 서명·묶음·충돌 없는 방·자리 스툴/매트·칠판·스포트, TableView 충돌 13개(메시 없음)·과녁 변환, 캐릭터 4명 몸짓 5종·바텐더, PlayerView 모델·레이어, 과녁 숫자 재배치·트리플 20칸, 다트 색·크기.
- `tests/render_game_look.gd`(새, 화면): 실제 `app/main.tscn`을 띄워 사람 3발 + 봇 차례 + 착석 1인칭까지 10장, 던지기 낱장 30장 → 저장소 최상위 `output/game_look/`(+ `11_throw.gif`).
