## 작업 내용

### 실제 경기 (F5, `app/main.tscn`)

- **테이블 집합 단계** `MatchState.Phase.TABLE`(enum 맨 뒤 = 7, 기존 2=AIMING·6=FINISHED 유지). 라운드가 넘어갈 때(마지막 제외) `table_seconds`(10초) 동안 연다. 사람 전원 착석 시 즉시 닫힌다.
- 시간 안에 못 앉은 사람: `GameView.force_seat`로 자기 자리에 앉히고 `MatchPlayer.speed_scale = slow_speed_scale`(0.5). 다음 집합 시작 때 1.0으로 해제. 봇 제외. 공지 "지각: … 자동 착석, 이번 라운드 이동 속도 50%".
- `speed_scale`은 MatchState 스냅샷으로 동기화, 방장 이동 시뮬레이션(`PlayerView.simulate`)이 곱한다. 머리 위 이름·점수판에 `슬로우` 표시.
- MatchController는 씬을 모른다 → `check_seated`/`force_seat` Callable 주입(`solve_throw`와 같은 방식).
- **오른쪽 버튼 충전 취소**: `DartThrowController.charge_cancelled` 신호. 취소 뒤 왼쪽을 놓아도 발사 안 함. HUD "충전 취소" 1.2초.
- 한글화: 봇 이름 "봇 N", 개발 모드 이름 "플레이어", 자리 "N번 자리", 벽 글자 "다트 파티 / 출입 금지", 로비 제목, HUD 안내(집합 남은 시간·자리 안내·슬로우 표시·충전/취소 안내), 흐름도 시연 제목·단계 설명.
- 설정: `default_match.tres`에 `table_seconds = 10.0`, `slow_speed_scale = 0.5`.

### 디자인 쇼케이스 (F6, `art/showcase`)

- 투척 시점: 3D 화면 클릭 → 마우스 잡기(1인칭 시선, 정면 기준 ±0.30rad), 조준점은 화면 가운데. Esc로 마우스 풀기, 다른 시점으로 가면 자동 해제.
- A/D: 투척선 위 좌우 이동 ±0.6m(1.2m/s), 충전 중에도 가능.
- 왼쪽 꾹 = 충전(`default_dart.tres`의 0.8초), 놓기 = 투척, 충전 중 오른쪽 = 취소, 포커스 잃으면 취소. 충전 막대, 손 다트가 충전량만큼 뒤로 당겨진다.
- 착탄: 실제 경기 `solve_dart`와 같은 식(속도 7~16m/s, 최대 속도 기준 중력 보정) → 최대 충전 = 조준점, 충전 0 ≈ 0.25m 아래. 비행도 실제 포물선.
- 화면 글자 전부 한국어(HUD·점수 이름 "불/트리플 20/빗나감"·크레딧 머리말). 3D 간판(`pub_builder.gd`) 한국어로 바꾸고 `pub.tscn`·캐릭터 씬 재생성. 엔진 라이선스 원문은 법적 고지라 그대로.
- 글꼴: Godot 기본 글꼴 + 시스템 대체 글꼴(맑은 고딕)로 렌더 확인. 배포 전 재배포 가능한 한글 글꼴 지정 필요.
