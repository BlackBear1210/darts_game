# 2026-10-28 F5 실제 경기에 카드 나눠 주기 붙이기

- 작업자 / 브랜치: Claude Code / `dev_1` (미커밋)
- 요청: "시작하자마자 카드를 줘야 할 거 아냐. 다트 던지는 거 시작하기 전에 각각 카드를 나눠 줘야 한다."

## 먼저 확인한 것

사용자가 카드가 없다고 한 화면은 **F5 실제 경기**였다. 카드는 F6 단독 시연 장면(`game/card_round/`)에만 있었고 실제 경기에는 전혀 없었다(시연 문서에도 "F5와는 연결하지 않았다"고 적혀 있다). 카드 라운드 씬 자체는 정상이었다 — 다시 돌려 딜링 화면까지 확인했다.

## 범위

**나눠 주기까지만** 붙였다. 카드를 꺼내 들고 쓰고 무효로 막는 것은 다음 단계다(네트워크로 확정·동기화할 것이 늘어난다).

## 바꾼 것

- `game/match/match_player.gd`: `hand` 을 옛 3종 계획(`CardDefinition`)에서 **카드 종류 번호 배열**(`Array[int]`, `card_catalog.gd` 기준)로 바꿨다. 안 쓰이던 `find_card()` 는 지웠다. 스냅샷에 그대로 실린다.
- `game/match/match_controller.gd`: `_begin_cards()` 추가 — 방장이 `CardHandRules.HAND_LIMIT`(7장)까지 **쓴 만큼만** 채우고 `Phase.CARDS` 를 `config.card_seconds` 동안 연다. 시작·재경기·테이블 집합이 끝난 뒤에 거친다. 카드 난수는 방장만 돌리고 결과는 스냅샷으로 나간다.
- `game/game.gd`: 1인칭 왼손 카드 부채를 카메라에 붙인다(`card_round` 의 `hand_fan.gd`·`card_faces.gd` 를 그대로 쓴다 — 카드 모양을 두 벌로 만들지 않으려고). 스냅샷이 올 때마다 손패와 맞추되 카드가 그대로면 다시 만들지 않는다. 화면 없는 서버·검사에서는 만들지 않는다.
- `ui/game_hud.gd`: "카드 나눠 주기" 단계 글과 `손패 7장 · 연산3 다트2 과녁2 물리0` 줄.
- `game/match/default_match.tres`: `card_seconds` 15 → **6초**(시연값). `tests/network_probe.gd` 의 `fast_match` 는 0.4초.

### 알림이 덮이던 것

`_close_table()` 의 "지각: … 슬로우" 알림을 바로 뒤에 오는 카드 알림이 덮어썼다. `_begin_cards(before)` 로 앞에 붙여 둘 다 보이게 했다.

## 실제 검증 결과

- 헤드리스 7종 PASS. `test_prototype` 에 **"다트 전에 모두 7장을 받는다"** 검사를 넣었고, 집합 뒤에도 카드 단계를 거치는 흐름에 맞춰 기다리는 지점을 고쳤다.
- 실제 화면(D3D12)으로 확인: 시작하면 `라운드 1 / 5 · 카드 나눠 주기 · 남은 시간 4.3초`, 손패 `연산3 다트2 과녁2 물리0`, 왼쪽 아래 1인칭 부채에 번호 1~7 카드가 보인다. 네 명 모두 7장이고 다트 단계로 넘어가도 유지된다. 확인 스크립트·그림은 `.godot/`(Git 제외).
- 네트워크 검증(`run_first_idea.py`·`run_multiplayer.py`)은 아래 "미검증"을 본다.

## 미검증 / 남은 작업

- **카드를 쓰는 것은 아직 없다.** 꺼내 들기·대상·효과·무효(×0)를 실제 경기에 옮기려면 방장 확정과 네트워크 메시지가 더 필요하다. 카드 라운드 시연의 "카드 턴"을 그대로 옮길지 팀이 정해야 한다.
- 봇은 카드를 받기만 하고 쓰지 않는다.
- 카드 보는 시간 6초는 시연값이다.
- 사람이 직접 F5를 돌려 본 느낌, 다른 PC·LAN, 전용 서버 재내보내기는 미검증.
