# 2026-11-25 · 피드백 네 가지 — 카드 크기 · 휠 넘기기 · 턴 60초 · 벌칙 시점

## 1. 오른쪽 위 적용 카드 크기 (`ui/active_cards.gd`)

카드 한 장 **62×93 → 96×144**(원본 400×600 과 같은 비율). 제목 16 → 19, 겹침 배지 17 → 22.
커진 만큼 한 줄에 보이는 수를 5 → **4장**으로 줄여 줄 폭이 화면을 넘지 않게 했다(넘치면 예전처럼 "+N").

## 2. 마우스 휠로 손패 넘기기 (`ui/lounge_hud.gd`)

휠 위/아래가 **Q·E 와 같은 동작**이다(`_browse_card`). F5 에서 휠을 쓰는 곳이 여기뿐이라 부딪히지 않는다
(감정표현 피자판의 휠은 F6 시연 전용이다). 아래 키 안내도 "Q · E" → **"휠 · Q · E"** 로 고쳤다.

## 3. 개인 턴 30초 → 60초 (`lobby/room_settings.gd`)

`dart_seconds` 기본값 30 → **60**. 범위(5~120)는 그대로라 방장이 설정에서 더 줄이거나 늘릴 수 있다.
`sanitize` 의 되돌림 값도 60 으로 맞췄다. 이 값이 `MatchConfig.turn_seconds` 로 넘어간다(확인함).

## 4. 벌칙 시점을 3인칭으로 (`game/game.gd`)

> "지금은 1인칭으로 화면이 빙글빙글 돌아가서 어지러움"

묶인 사람 눈에서 보던 것을 **레인 옆에 고정한 자리**로 바꿨다(`PUNISH_VIEW`).
방은 가만히 있고 **판 위의 내 몸만 돈다** — 어지럽지 않고 몇 대 맞았는지도 눈으로 보인다.

자리: `Vector3(-2.9, 2.6, 과녁z + 3.2)` 에서 과녁 중심을 본다.
쓰이지 않게 된 1인칭 눈 계산(`BoardView.victim_eye`, `BoardVictim.EYE_FORWARD`)은 지웠다.

**맞바꾼 것**: 던지는 사람이 카메라 뒤에 있어 **다트가 날아오는 것을 미리 보지 못한다.**
어지럼증을 없애는 쪽을 골랐다. 날아오는 다트까지 보이게 하려면 카메라를 레인 옆으로 더 빼야 하는데
그만큼 내 몸이 작아진다 — 눈으로 보고 정할 값이다.

## 검증

- 실제 라운지 경기를 돌려 확인(`.godot/check_four.gd`):
  - 방 설정 60초 → 경기 설정 60초로 넘어옴. 화면 타이머가 58 부터 센다.
  - 휠 내리기: 꺼낸 칸 −1 → 0 → 1 (Q·E 와 같게 넘어간다).
  - 오른쪽 위 카드 줄 크기 302×174(96 짜리 3장 + 사이).
  - 벌칙: 내가 묶였을 때 카메라가 `(-2.9, 2.6, -7.6)` 으로 고정되고 화면에 내 몸이 판 위에서 돈다.
  - 사진으로 커진 카드·"휠 · Q · E" 안내·벌칙 3인칭 화면을 확인했다.
- 헤드리스 `tests/test_*.gd` 전체.
- **검증하지 못한 것**: 사람이 실제로 휠을 굴리는 감(한 칸씩 넘어가는 속도가 적당한지),
  60초가 늘어진다고 느껴지는지, 벌칙 시점에서 다트가 안 보이는 것이 답답한지. 다중 프로세스 멀티.

### 고친 시험 하나

`tests/test_lounge_rules.gd` 가 `dart_seconds` 기본값 **30 을 못박고** 있었다(이상한 입력을 넣고 되돌림 값을 보는 검사).
기본값을 60 으로 바꿨으니 시험도 60 으로 고쳤다.

### 내가 고치지 않은 깨진 시험 — `tests/test_arcade.gd`

**"파워 카드로 던진 큐대는 부러진다"가 실패한다. 내 네 가지 수정 전부터 깨져 있었다** —
팀원 커밋 `de2b4c5`(승인 캐릭터와 **소품 잡기** 및 봇 대기 자세)를 받은 직후의 전체 시험에서 이미 실패했고,
그때 `test_lounge_rules` 는 통과했다.

- 선행 런타임 오류는 없다. 단순히 `lounge._launch(cue, ...)` 뒤 0.8초 안에 `objects[cue].broken` 이 서지 않는다.
- 그 커밋은 `lounge_world.gd` 의 `_launch`(`set_down` 지우기)와 `_physics_process`(머그 내려놓기),
  `_process`(머그 잡는 손 `MugMotion.place`)를 건드렸다.
- 남의 담당 영역이라 손대지 않았다. 공유 브랜치의 시험이 깨진 상태이므로 팀원에게 알려야 한다.
