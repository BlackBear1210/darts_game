# 2026-10-28 카드 라운드에 "카드 턴" 넣기

- 작업자 / 브랜치: Claude Code / `dev_1` (미커밋)
- 요청: "card_round 씬을 다들 한 턴씩 돌고 하고 싶어" → 실행해 보여 드린 뒤 "카드턴이 없는디?"

## 전까지의 동작

카드 단계는 딜링 → 공개 → **전원이 동시에** 꺼내 들 수 있는 "카드 확인" 시간이었고, 카드는 **다트 단계 중 아무 때나** 누구나 쓸 수 있었다. 한 사람씩 돌아가며 내는 단계가 없었다.

## 사용자가 정한 것

| 물음 | 답 |
| --- | --- |
| 카드 턴을 어디에 둘까 | "시작할 때 나눠줌. 라운드 다 돌면 한 번 더" → **나눠 주기 → 카드 턴 한 바퀴 → 다트**, 다음 라운드에 다시 |
| 한 턴에 몇 장 | **한 장 또는 패스** |
| 다트 중 대응(무효·방해)은 | **카드 턴에만** |

첫 답이 선택지 밖이라 위와 같이 읽었다. 다르면 `_run()`의 단계 순서 한 줄이다.

## 바꾼 것

- `flow/round_context.gd`: `card_turn_seat`(지금 누구의 카드 턴), `card_used_by`(이번 턴에 쓴 사람), `passed`(사람이 Enter).
- `card_round.gd`: `_card_turn_stage()` + `_card_turn(seat)` 추가, `_run()` 순서를 `카드 단계 → 카드 턴 → 다트`로. `_dart_stage()` 시작에서 `ctx.cards_open = false`.
- `flow/card_actions.gd`: `can_lift()` — 자기 카드 턴이면 아무 카드나, 남의 턴이면 **막을 대기 카드가 있는 대응 카드(무효 ×0)만**. 사람이 못 내는 키를 누르면 이유를 알린다. 카드를 쓰면 `card_used` 신호.
- `rules/bot_brain.gd`: 판단 기준이 "다트 중인가"에서 **"내 카드 턴인가"**로 바뀌었다. 남의 턴에는 대응 카드만 고른다.
- `flow/local_input.gd`: **Enter / 넘패드 Enter = 패스**.
- `flow/hud_presenter.gd`: 아래 안내를 단계별로("내 카드 턴 · 1~7 → F · Enter 패스" / "○○ 카드 턴 · 무효로 대응 가능" / 다트 중에는 "카드는 카드 턴에만").

### 해석해서 넣은 예외

"카드 턴에만"을 글자 그대로 하면 **무효(×0) 카드가 죽는다** — 그 카드의 대상이 "남이 꺼내 든 대기 카드"라서 자기 턴에는 쓸 일이 없다. 꺼내 들기 → 1.2초 안에 막기라는 심리전도 사라진다. 그래서 대응 카드만 남의 카드 턴에도 낼 수 있게 했다. 되돌리려면 `card_actions.can_lift()` 한 곳에서 `COUNTER` 예외를 지우면 된다.

## 미검증 / 남은 작업

- 사람이 직접 자기 카드 턴에 내보고 Enter로 패스해 본 조작감(봇으로만 확인했다).
- 카드 턴 제한 시간(사람 20초 · 봇 3.5초)은 시연값이다.
- 한 턴에 한 장이라 카드가 느리게 소모된다(이번 실행은 4명 중 3장 사용). 7장을 다 쓰려면 라운드가 꽤 필요하다 — 보충 규칙("쓴 만큼만")과 함께 팀이 볼 값이다.
- 대응 카드 예외를 팀이 확정해야 한다(위 "해석해서 넣은 예외").
