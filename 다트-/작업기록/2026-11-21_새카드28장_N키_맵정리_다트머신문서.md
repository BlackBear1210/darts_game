# 새 카드 28장 · 준비 시간 없앰 · N 키 안내 숨기기 · 펍 정리 · 점수 팝업 소수 · 다트머신 문서 (2026-11-21)

사용자 요청(한 번에 여러 개, CARD_PLAN.md 첨부):
1. 카드를 들거나 바꾼 뒤 "준비 중" 기다림 없애기 · 카드 종류 다시 확인(CARD_PLAN 에서 지운 속도 카드가 살아났다) · 사용자 카드 13장 + 추천 카드 15장을 종류에 맞게 만들고 모두 작동 · 구역 지목은 무작위 구역.
2. 배그처럼 N 키로 키 안내 켜고 끄기.
3. 펍: 모니터를 가리는 NPC 옮기기 · 카드 테이블 뒤 벽쪽 NPC 4명과 테이블 지우기 · 두 맵(펍·오락실) 배치도를 바탕화면에.
4. 다트 머신: 카드·행동 상호작용과 시너지, 지금 머신의 오류, 효과가 겹칠 때 모습을 Codex 용 차례 프롬프트로 바탕화면 `다트머신_디자인` 에(효율·SOLID·스팀 출시 안전 리서치 포함).
5. 확인용 gd·스크립트 지우고 자세한 커밋으로 푸시 · 유지보수(틀 잡힌 부분은 한 파일로 붙이는 모듈) · 바탕화면 `DARTY_프로젝트` 에 작업 프롬프트 + 밀린 기록 갱신.
6. 질문: 팀원이 바꾼 캐릭터(손가락·움직임·박스 같은 옷)를 블렌더/3ds Max 에서 직접 고쳐야 하나? → 아래 §8.

## 1. 카드

### 1-1. 준비 시간 없앰
- 카드를 꺼내 들거나 바꾼 뒤 기다리던 "준비 중"을 없앴다. 꺼내면 바로 쓸 수 있다(`RoundRules.use_problem` 이 바로 빈 값).
- HUD 준비 막대는 `READY_SECONDS <= 0` 이면 꽉 찬 것으로 본다(나눗셈 0 방지, `ui/lounge_hud.gd`).
- 시험: `test_card_round`("꺼내면 바로 쓸 수 있다") · `test_lounge`(들자마자 쓰기).

### 1-2. "속도 카드가 살아난 것" 정리
- CARD_PLAN: "속도 증가는 삭제하고 투척 힘 증가로 통합(확정)". 게임에는 `power_up` 이 "힘 증가 — 투척 **속도** 1.3배" 라는 글로 남아 있어서 지운 카드처럼 보였다.
- 이름을 **투척 힘 증가**로, 글에서 "속도"를 뺐다(효과는 그대로 비행 빠르기 ×1.3). 이동 속도는 새 카드 **이속 증가·감소**가 맡는다.
- 옛 카드(+10 · ×2 · −20)는 `"legacy": true` 로 나눠 주지 않는다(그대로). 이걸 쓰던 `test_bot_cards` 를 지금 카드(졸림·투척 힘 증가)로 바꿨다.

### 1-3. 새 카드 28장(사용자 13 + 추천 15) — 카드 목록 맨 뒤(종류 번호 31~58, 전체 59장)
| 종류 | 카드 |
|---|---|
| 연산 | 가로채기 · 반띵 · 홀짝 |
| 다트 | 좌표 고정 · 관통 다트 · 고무 다트 · 카드 던지기 |
| 과녁 | 과녁 크기 변화(×0.7/×1.35) · 링 확장(트리플·더블 2.5배) · 지뢰 심기 |
| 물리 | 이속 증가 · 이속 감소 · 속박 · 끌어당기기 · 키 변화(거인/꼬마) · 정전 · 딸꾹질 · 유체이탈 · 망원경 · 원샷 |
| 특수 | 차례 바꾸기 · 점프 · 타이머 감소 · 목소리 변조 · 강제 음소거 · 소매치기 · 왕머리 · 랜덤 카드 |

- 새 표시(카드 목록 칸): `"mod"`(효과 이름 — `RoundRules.dart_modifiers` 에 그대로 실림) · `"value"`/`"values"`(무작위 하나) · `"solo"`(협동 강화 없음, 같은 효과가 걸려 있으면 "이미 적용 중") · `"aim"`(바라보는 쪽 첫 사람) · `"live"`(F5 펍 경기 전용 — F6 단독 시연은 안 나눠 줌).
- 새 대상 `Target.PICK`(Tab 으로 고른 사람) · 새 시점 `Timing.INSTANT`(쓰는 순간 한 번).
- 쓰는 순간 처리(차례 바꾸기·점프·타이머 감소·지뢰·속박·끌어당기기·소매치기·랜덤 카드)는 **새 모듈 한 파일** `game/match/match_card_actions.gd`(`context_problem` = 지금 쓸 수 있나, `apply` = 처리).
- 세상에 닿는 처리(속박 구역·끌어당기기·카드 던지기 맞히기)는 **새 모듈** `game/match/card_world.gd`.
- 내 화면 효과(정전·망원경·딸꾹질·유체이탈·원샷)는 **새 모듈** `game/match/card_screen_effects.gd`(셰이더 2장, 스스로 ColorRect 를 만든다).
- 판정: 홀짝(÷2/×2)·지뢰(−15/칸, 경기 끝까지, 최대 5)·가로채기·반띵(계산이 다 끝난 점수에서 뗌) = `RoundRules.resolve_dart`. 과녁 크기·링 확장 = `BoardChaos`·`BoardLayout.ring_edges` 하나를 그림과 판정이 같이 쓴다.
- 고무 다트 겉모습(튕겨 두 구간 포물선) = `game/dart/dart.gd`. 키 변화·왕머리·이속 = `game/player/player.gd`(충돌 캡슐은 그대로 — 작아져도 몸막 판정이 쉬워지지 않게). 목소리 변조·강제 음소거 = `network/voice_chat.gd`(방장 중계에서 버리고 재생 전에 한 번 더).
- 협동 강화(`supports_synergy`)에서 INSTANT 카드를 뺐다(쌓을 효과가 없어 시험이 사전 오류를 냈다).

### 1-4. 구역 지목 = 무작위 구역
- 쓰는 순간 무작위 숫자 구역을 정해 판에 표시(`marked_sector`). 맞히면 +15, 틀리면 그 구역 숫자 × 싱글 배수만큼 −.
- 시험 `test_card_plan` 이 무작위로 정해진 구역을 읽어 확인한다.

## 2. N 키 — 키 안내 켜고 끄기
- `ui/player_preferences.gd` `show_key_hints`(설정 파일 `display/key_hints`, 껐다 켜도 기억).

## 3. 펍·오락실 맵
- 모니터를 가리던 바 손님 `Guest_5`(가운데 스툴 z 2.5) → 모니터 뒤쪽 첫 스툴(z 0.95). 바텐더 서빙·오락실 매점 손님도 0·2번 스툴.

- 경기 방 그림 `art/pub/pub_game.tscn` 다시 생성(배치 서명 갱신 — `test_game_look` 이 확인).

## 4. 점수 팝업
- 소수 점수(홀짝 ÷2 의 3.5)를 반올림해 판정과 다르게 보이던 것 → "+3.5" 그대로(`art/fx/score_popup.gd` `number_text`).
- 지뢰·뺏김으로 0점 이하가 되면 "MISS" 로 보이던 것 → "MINE!" / "-20 TAKEN"(`note`). `MatchCards.score` 가 `taken` 합을 넘기고 `MatchController._land_dart` 가 `last_hit.taken` 에 싣는다.

## 8. 질문 답 — 캐릭터를 블렌더에서 고쳐야 하나
- **블렌더**로 고친다(3ds Max 아님). 원본이 `.blend`(`character_assets/approved_rig_20261119/character_source.blend`)이고 게임 모델은 `character_assets/approved_game_character_20261119/build_game_character.py` 로 다시 만든다.
- 손가락: 승인 손에는 **손가락별 변형 가중치가 없다**(11-19 기록에 "후속 작업"이라고 적혀 있음). 그래서 코드로 손가락을 굽혀도 살이 안 따라온다 → 블렌더에서 손가락 웨이트 칠하기(또는 "쥔 손" 모양 키) 필요.
- 움직임이 끊김: `art/characters/character_pose_safety.gd` 가 매 프레임 목·쇄골·손목 각도를 **딱 잘라** 막고 팔을 밀어낸다 → 경계에서 툭 튄다. 근본은 블렌더에서 클립 자체를 실제 몸에 맞게 고치기. 코드로는 부드러운 한계·보간이 도움이 되지만 팀원 파일이라 먼저 물어봐야 한다.
- 박스 같은 옷: `Top_01`/`Bottom_01` 은 GLB 메시라 Godot 에서는 옮기기·크기만 가능. 어깨·팔꿈치·허리에 고리(edge loop)를 더하고 몸에서 웨이트를 옮겨(Data Transfer) 부드럽게 해야 한다 → 블렌더.
