# 2026-11-22 경기 HUD 검정 배경 제거 · 점수판 정리 · 카드 테이블 흰 선 칸

- 작업자 / 브랜치: Claude Code(디자인 담당 요청) / `dev_1`
- 요청(요약):
  1. 왼쪽 위 플레이어 목록은 **첫 로비(라운지)에서만** 크게 띄우고, 경기 중에는 **이름과 점수만**.
  2. UI 뒤 **검정 배경을 없애** 게임 화면을 덜 가리게. "테두리가 왜 삐딱한지 모르겠다 — 그걸 없애는 대신 뒷배경만 없애 봐."
  3. 카드 테이블의 **자리마다 색 구역을 없애고, 포커 테이블처럼 카드 놓는 곳만 흰 선**으로.
  4. 굳은 부분은 **씬이 아니라 파일 하나(`.new()`)로 붙는 모듈**로 — 다른 작업자가 편집기에서 찾기 쉽게.

## 테두리가 삐딱했던 이유

`ui/lounge_style.gd` 의 `SKEW = -0.08` 이다. 2026-10-30 UI 개편 때 "다트 깃처럼 비스듬한 판"으로 정한 디자인이라
`Style.card()` 가 모서리 반지름 16 이하인 판을 전부 이 값만큼 기울인다(그래서 **판이 있는 UI 는 전부** 삐딱했다).
이번에는 요청대로 **기울기는 그대로 두고 경기 HUD 의 판(배경)만 없앴다** — 판이 없으니 경기 화면에서는 기울어진 테두리도 함께 사라진다.
메뉴·설정·결과 창처럼 판이 남은 곳은 여전히 기울어 있다. **전부 곧게 하려면 `SKEW` 를 `0.0` 한 줄만 바꾸면 된다**(코드 주석에 적어 둠).

## 바꾼 것

### 1. 경기 HUD — 판 대신 글자 외곽선

| 자리 | 전 | 후 |
|---|---|---|
| 왼쪽 위 점수판 | 검정 판 + DARTY 로고 + "라운지" + 자리별 줄(늘 같은 모양) | **라운지(대기)**: 로고 + "라운지" 제목 + 줄. **경기 중**: 제목 없이 `기호 · 이름 · 점수` 줄만. 판 없음 |
| 위 가운데 라운드 표시 | 검정 판 | 판 없음. "R 2/5" 와 단계 글자에 잉크 외곽선, ◆·● 칸 둘레에 작은 잉크 받침(HALO) |
| 오른쪽 위 방 정보·킬로그 | 줄마다 검정 판 | 판 없음. 글자 외곽선, **아이콘만 작은 동그란 받침**(크림색 선 아이콘이 크림색 벽에 묻혀서) |
| 오른쪽 아래 꺼낸 카드 | 검정 판 | 판 없음. 카드 그림은 그대로, 글자는 외곽선 |
| 안내 토스트 · 준비 표시(✓/○) | 작은 판 | 판 없음. 글자 외곽선. 준비 표시 칸 사이 10 → 22px |
| "내 차례가 아니에요!" | 분홍 판 | 판 없음. 분홍 큰 글자 + 크림 작은 글자 |
| **남긴 것** | 결과 창(경기가 멈추는 화면이라 판이 있어야 읽힘), 키캡, 방 코드 복사 버튼 | |

- 글자 외곽선은 `Style.outline(label, size)` / `Style.hud_label(...)` 한 곳에서 만든다:
  잉크색 외곽선(글자 크기의 1/4, 최소 5px) + 같은 굵기의 아래쪽 그림자. **판 없이도 밝은 벽·네온 앞에서 읽히는 최소한의 받침**이다.
- 참고: Xbox 접근성 지침 XAG 101(글자 표시)·102(대비) — 배경이 움직이는 게임 화면 위 글자는 외곽선·그림자나 얇은 받침으로 대비를 확보하라는 권고.
  판 전체 대신 외곽선을 고른 이유가 이것이다(화면을 덜 가리면서 대비를 지킨다).

### 3. 카드 테이블 — 색 구역 → 흰 선 칸(포커 테이블 방식)

- `art/pub/room/room_seating.gd` `build_table_and_seats`:
  - **지움**: 자리 색 매트(`PlayerMat`), 칸 홈(`CardSlot`), 예약 2칸(`ReserveSlot` — F5 경기에서는 한 번도 안 쓰여 늘 비어 있었다), 자리 기호(`SeatSymbol`).
  - **넣음**: 손패 칸(`CardHandRules.HAND_LIMIT` = 7칸)마다 흰 둥근 사각형 선 `CardSpot`. 칸 자리는 `TableCards.SLOT_X0/SLOT_GAP/SLOT_Z` 를 그대로 써서 **진짜 카드가 놓이는 자리와 정확히 같다**.
  - 자리 노드 `SeatMat_N` 이름은 유지(`TableView.show_seats` 가 이 이름으로 빈 자리를 숨긴다). 자리 색은 러그·의자 테두리에 남아 있어 누구 자리인지는 계속 보인다.
- `game/card_round/cards/table_cards.gd` `MAT_TOP` 0.017 → 0.006: 매트가 없어져 카드가 펠트 위에 바로 눕는다.
- **왜 셰이더인가**: 처음엔 3mm 선을 메시로 만들었는데, 라운지에서 멀리 보면 선이 1화소보다 가늘어져 **점선처럼 끊기고 반짝였다**(프로젝트는 MSAA·FXAA·TAA 를 안 쓴다).
  그래서 판 하나 위에 둥근 사각형까지의 거리(SDF)로 선을 그리고, `fwidth` 로 화면 화소 굵기를 재서
  **선이 1화소보다 가늘어지면 굵기는 1화소로 두고 그만큼 옅게** 그린다 → 가까이선 또렷, 멀리선 끊김 없는 옅은 선.
- 포커 테이블 레이아웃 참고: 펠트 위에 카드·칩 놓는 자리를 **선만으로** 표시하는 방식(위키백과 Poker table, 카지노 펠트 레이아웃 글). 공통 규격·상표 문제 없는 일반 디자인이다.
- `art/pub/pub_game.tscn` 은 `pub_builder.gd -- --game-room-only` 로 다시 생성했다(생성기가 결정적이라 바뀐 칸 말고는 번호만 다시 매겨짐 — 수정 전 코드로 다시 만들면 HEAD 와 바이트까지 같은 것을 확인).
- 아트 쇼케이스 펍(`art/pub/pub.tscn`, `pub_builder.gd table_area`)의 전시용 색 매트는 **게임에 안 나오는 장면**이라 건드리지 않았다.
