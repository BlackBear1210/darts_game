## 1. 협동 시너지 제거

2026-11-12에 들어간 규칙(서로 다른 2명 1.5배 · 3명 2배, 방해카드 16종)을 걷어냈다.
이제 **같은 효과는 대상에게 한 번만** 걸린다 — 두 번째로 낸 사람은 "이미 적용 중"으로 거절되고 카드도 안 쓴다.
2026-11-21 새 카드들이 이미 쓰던 규칙(`"solo"`)을 전체로 넓힌 것이라 카드 규칙이 하나로 통일됐다.

## 2. 개발자 모드

### 2-1. 게임 안에서 켜기
- ESC → 개인 설정 맨 아래 **「개발자 모드」 토글**(`Main.set_developer_mode`). 예전에는 `--developer` 로 실행해야만 켤 수 있었다.
- **개발 빌드에서만** 보이고 켜진다(`OS.is_debug_build()`). 내보낸 게임에는 항목이 없다.
- 켜면 경기·연결에 바로 전해진다(`GameView.developer_enabled` · `MatchController.developer_enabled` · `NetworkSession.developer_authorized`).

### 2-2. 카드 시험대 (설정 → 개발자)
- 지금 쓸 수 있는 카드 **전부**를 종류별로 늘어놓고, 누르면 **손패와 상관없이 바로 쓴다**.
- **진짜 사용 경로를 그대로 지난다**(`MatchCards.developer_play` → `_use` → `_after_use`). 카드를 빈 칸에 넣고 꺼내 드는 과정만 건너뛴다 →
  시험대에서 되는 것은 경기에서도 되고, 안 되면 **왜 안 되는지가 아래 줄에 뜬다**(차례·대상·이미 적용 중).
- 대상 고르기: 기본은 "지금 던지는 사람". 「상대 1명」·「Tab 지목」 카드에만 쓰인다(나에게 거는 카드·무효는 카드가 정한 쪽이 먼저다).

### 2-3. 경기 조작 (설정 → 개발자)
- 내 점수 ±10 / ±50 / 0으로 · 차례 끝내기(F3과 같다) · 걸린 카드 효과 모두 지우기 · 투척선 뒤로 옮기기.

### 2-4. 권한
치트는 전부 방장 쪽에서 `multiplayer.is_server() and developer_enabled` 를 **다시 확인한다**.
클라이언트가 자기 화면에서 토글을 켜도 남의 경기를 바꾸지 못한다. 방 규칙(카드 on/off·가중치)은 예전처럼 `developer_authorized and sender == HOST_ID` 다.

## 미검증 / 남은 작업

- 시너지가 사라져 **방해 카드가 약해졌다**. 2·3인이 몰아쳐도 한 장 분량이라 밸런스를 다시 봐야 한다(팀 확정 대기).
- `docs/CARD_PLAN` 계열 문서에 시너지 표가 남아 있으면 팀이 같이 정리해야 한다(이번에는 코드와 `DECISIONS`·`ARCHITECTURE` 만 고쳤다).
- 카드 시험대는 **방장 화면 전용**이다. 클라이언트에서 남의 경기에 카드를 꽂아 보는 기능은 넣지 않았다.
- 개발자 모드를 켠 채로 경기를 오래 돌려 본 적은 없다(시험과 확인 화면 수준).
