1. 카드 라운드의 카드 섞는 효과가 전부 사라졌다 → 싱글·멀티 둘 다 다시 되게.
2. 네온 오락실 벽 글씨가 창문과 겹쳐 잘린다.
3. 펍·네온 오락실 맵을 더 넓히고 층고를 조금 높인다.
4. 네온 맵은 펍과 다르게 **네온 사인 + 인형뽑기 가게** 느낌, 조명·오브젝트·오락기, **바텐더 대신 주스·음료 가게**. 맵 특성은 살리되 게임 시스템·흐름은 건드리지 않는다.
5. 에셋은 받은 압축 파일(또는 Godot 용 무료 에셋)에서 직접 찾아 넣는다. 코드로 만든 맵이 갈라져 보이는 것도 정리한다.
6. Godot 에서 흐름·오류·변수·방해 공작이 도는지 확인 → 문서 갱신 → 설명 달아 커밋·푸시.

## 1. 카드 섞기 — 왜 "사라졌나"와 복원

- **원인**: 섞기 모션(정석 리플·마술사·딜러)과 덱에서 한 장씩 날아가는 나눠 주기는 F6 카드 라운드 시연(`game/card_round/`)에만 있었다. F5 경기(`game/game.gd`)는 카드를 매트에 바로 깔기만 했고 연출을 연결한 적이 없다.
- **복원** `game/table/deck_show.gd`(새 파일, 보이기만 하는 노드):
  - 스냅샷이 CARDS 단계(카드 확인 5초)로 들어오면 각 화면이 스스로 재생: 쓴 카드가 덱으로 돌아옴 → 섞기 → 한 바퀴에 한 사람 한 장씩 나눠 주기.
  - 섞는 방식 = `posmod(match_id + 라운드, 3)` → 싱글·방장·손님 모든 화면에서 같은 방식이 보인다(따로 보내는 데이터 없음).
  - 새 카드는 매트에서 숨겼다가(`SeatCards.hold`) 덱에서 날아와 닿는 순간 뒤집히며 나타난다(`release`).
  - 5초 안에 끝나도록 섞기 속도를 맞춘다: `ShuffleMotions` 에 `shuffle_speed` 메타(시연 F6 은 1배 그대로). 다트 단계가 먼저 오면 남은 연출을 건너뛰고 매트를 모두 보인다.
  - 소리: `Sfx` "riffle"(촤라락) · "deal"(휙) 추가.
  - 규칙·타이머·네트워크·손패(1인칭 부채) 표시 시점은 그대로다.
- **검증**: `tests/render_match_ui.gd`(싱글, 섞는 중 화면 + 끝나면 매트 28장 · 덱 20장), `tests/run_deck_show_remote.py`(새 파일: 실제 ENet 방장 헤드리스 + 손님 창 모드, 1라운드 첫 나눠 주기와 2라운드 충전 둘 다 손님 화면에서 재생되는지, 다트 시작 때 숨은 카드 0장).

## 3. "갈라져 보이는 맵" 정리(펍 생성기 `_shell`)

- 바닥: 판자 틈 사이로 배경색(빈 공간)이 보였다 → 어두운 밑판을 깔아 틈이 홈으로 보인다. 판자는 칸(다트 홀·라운지)별로 깔고 경계에서 잘라 ㄱ자 모서리에 빈 곳이 없다. 줄마다 이음매를 엇갈렸다.
- 벽: 모든 벽판을 양끝 0.18 m 늘리던 탓에 튀어나온 모서리(다트 홀 옆벽 ↔ 단차 벽)에서 벽판이 방 안으로 삐져나왔다 → 그 끝은 늘리지 않고 모서리 기둥으로 이음매를 덮는다. 징두리·난간·몰딩은 제 두께만큼만 늘려 맞물린다.
- 천장: 두 칸 천장판이 z=0 에서 0.4 m 겹쳐 깜빡였다(z-fighting) → 맞붙였다. 라운지 보는 길이에 맞춰 3개.

## 4. 네온 오락실 개편(`game/lounge/arcade/arcade_room.gd` 다시 씀)

- **창 없는 방**: 펍의 창문을 `Windows` 묶음으로 따로 빼고 오락실에서는 통째로 뺀다(`LoungeWorld.ARCADE_SKIP`). 간판은 글자 크기로 판 크기를 계산해 거는 `_neon_sign` 으로 바꿨다 → 예전처럼 글자가 창·과녁 판넬 뒤로 들어가 잘리지 않는다.
  (예전 "GAME OVER? INSERT DART" 는 창이 아니라 과녁 초록 판넬·캐비닛 문 뒤에 있어 잘렸다 — 판넬(x ±2.7) 바깥으로 옮김.)
- **주스 가게**(바 자리, 바텐더 대신): 보라 카운터 + 하얀 윗면 + 네온 타일, 주스 디스펜서 3대, 컵·믹서, 과일, 빨간 다이너 의자, 안쪽 금속 선반·싱크대·메뉴판·줄무늬 차양, "FRESH JUICE / 생과일 주스 · 음료" 간판, **주스 가게 직원**(바텐더 모델: 조끼·나비넥타이·콧수염 숨기고 청록 후드·분홍 앞치마·모자).
  - 음료병 소품 자리(카운터 방 쪽 절반)는 비워 뒀다 — 병 집기·마시기·던지기 그대로. 메뉴판 값은 장식(돈 규칙 없음).
- **인형뽑기 코너**: 진짜 기계(규칙 그대로) 옆에 장식 기계 4대(ㄱ자, 인형 7개씩) + 뒷벽 인형 진열 선반 2단 + 기계 위 큰 오리 인형 + "CLAW · 인형뽑기" "PRIZE ZONE" 간판 + 분홍 조명.
- **오락기**: 뒷벽 6대 + 다트 홀 옆벽 4대(투척 구역 밖 벽쪽). 이 테마에서만 충돌.
- **천장·벽**: 벽 위 네온 레일, 천장 보 아래 네온 관. 네온은 저마다 기본 밝기의 ±11% 로 숨 쉰다.
- **소품**: 가챠 뒤 사탕 병, 냉장고 위 화분, 휴지통.
- 움직이지 않는 메시는 `Static` 아래 모아 화면이 있을 때 `StaticBatch` 로 묶는다(같은 재질은 한 번만 만든다). 인형 재질은 장식용만 같이 쓰고, 손에 드는 인형 소품(`prop_looks.gd`)은 따로 만든다.
