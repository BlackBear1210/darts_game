## 사용자 요청(요약)

1. 주크박스가 화분과 겹친다.
2. 바의 사람은 선수와 디자인이 다르고 의자에 앉아 있지도 않다.
3. 예시 프롬프트처럼 맵 디자인을 바꿔야 하는데 다트판만 바뀌었다.
4. 가림막 카드는 판때기로 가리지 말고 차고 문·가게 셔터처럼 옆에서 촤라락.
5. 감정표현 이모지가 아래 UI 를 가린다.
6. 지형지물·벽·창문·테이블 다리 등이 전부 이상하다. 폴리곤은 적고 점토 느낌이지만 디테일 있게, Claude 가 직접 3D 모델을 만들어라.
7. 못 만드는 것은 Codex(gpt-6.1 sol)로 뽑을 수 있게 요청 프롬프트 파일을 만들어라.

## 작업 내용

### 1. 점토 메시 도구 `art/pub/round_kit.gd` (새 파일)

Blender 없이 코드로 "적은 폴리곤 + 둥근 구조" 모델을 만드는 도구. 요청서 2장 "부드러움은 폴리곤 수보다 구조에서"를 그대로 옮겼다.

- `lathe`(단면 돌리기: 다리·받침·전등·화분·병)
- `sweep`(단면을 길 따라 쓸기: 아치 틀·몰딩·난간·커튼)
- `rounded_slab`·`slab_mesh`·`panel_mesh`(둥근 판, 윤곽을 밀어 올린 판)
- `tube`·`rod`·`ring`·`sphere`
- 법선은 부드럽게, 단면에 같은 점을 두 번 적으면 그 자리만 각진 모서리
- 같은 위치·같은 법선 꼭짓점을 합친다(`index`). UV 는 저장하지 않는다(단색 점토 재질).
- 같은 모양은 한 번만 만든다(캐시).

### 2. 경기 방 다시 만들기 `art/pub/game_room_builder.gd` → `art/pub/pub_game.tscn`

| 부분 | 예전 | 지금 |
|---|---|---|
| 바닥 | 판자 상자 수백 개(틈 사이 밑판이 보임) | 평평한 판 한 장 + 헤링본 오크 셰이더(`art/pub/roundhouse_floor.gdshader`, 세계 좌표라 이음매 없음) |
| 벽 | 평평한 상자 벽 | 크림 회벽 + 청록 판벽(홈 패널) + 허리 난간 + 걸레받이 + 월넛 기둥·아치 틀(칸 나누기) + 코니스 + 빛나는 코브 |
| 벽 계획 | 물건이 벽 장식과 겹침 | 창·액자·문·주크박스·선반 자리를 먼저 정하고 기둥이 그 사이에만 서게 계산(`_walls`·`_bays`) |
| 창문 | 네모 창 | 아치 창 + 창살 + 부채꼴 + 커튼 두 장 + 커튼 봉 |
| 카드 테이블 | 상자 다리 | 트럼펫 모양 받침(회전체) + 펠트 상판 + 둥근 테두리 + 원형 러그 |
| 의자 | 상자 스툴 | 클럽 의자(둥근 쿠션 + 140° 등받이 + 끝이 가는 다리 + 황동 캡) |
| 바 | 상자 카운터 | 둥근 몸통 + 대리석 상판 + 황동 발받침 + 탭 + 종 + 바 스툴(발 링) + 아치 뒤 선반(병 진열) |
| 당구대·문·화분·액자 | 상자 | 둥근 몸통·회전체 다리·주머니, 아치 문 + 유리, 회전체 화분 + 잎 12장, 자체 기하 액자 |
| 조명 | 천장 전구 줄 | 펜던트 등(갓·안쪽·전구) + 벽등(빈 칸 가운데) + SSAO(접촉 그림자) |

- 크기·충돌·자리 상수는 `TableView` 그대로다. 충돌은 바꾸지 않았다.
- 실행 중 메시 묶기(`static_batch.gd`)와 오락실 테마 색 바꾸기(재질 이름 기준)가 그대로 돈다.
- 오락실 테마는 펍 벽 위에 남색·자두색을 칠한다. 새 재질 이름(LeatherTeal·WoodPanel·CeilingPlaster·CovePlaster·RugTeal·CoveGlow)을 `LoungeWorld._recolor` 에 더했다.
- 파일 크기: 처음 5.2MB → `MeshKit.rounded_box_mesh` 에 점 합치기(`index`) + UV 빼기 → 2.6MB. 예전 1.1MB 보다는 크다. 크기가 다른 둥근 상자가 수십 개라서다.

### 3. NPC — 선수와 같은 리깅 캐릭터 (`art/pub/npc_idle.gd` 다시 씀)

- 펍 손님 4명·바텐더·오락실 주스 가게 직원이 선수와 같은 `art/characters/rigged/player_character.tscn` 을 쓴다.
  - 셔츠 색·안경만 다르다.
  - 몸짓은 `CharacterMotion`(앉기·서기·마시기·가리키기)이다.

- 높은 바 스툴(앉는 면 0.8m)은 `seat_top` 만큼 몸을 올려서 실제로 스툴 위에 앉는다.
- 오락실에서는 펍 손님 묶음(`Guests`)을 뺀다(`ARCADE_SKIP`).

### 4. 주크박스·모니터 (`game/lounge/lounge_world.gd`)

- 주크박스를 (8.6, 0, 0.5)로 옮겼다. 화분과 겹치지 않는다.

### 5. 롤 셔터 — 가림판 카드 (`art/dart_machine/roll_shutter.gd` 새 파일)

- **모양**
  - 어깨 앞 세로 셔터 통, 위·아래 레일, 앞 바(손잡이), 좁은 날개 13장(한 장 걸러 조금 어둡게)
  - 다 열리면 날개가 모두 통 안에 숨는다. 예전처럼 판자 더미가 어깨 앞에 남지 않는다.
- **움직임**
  - 앞 바가 통에서 가운데로 달려 나가고, 날개가 한 장씩 통에서 빠져나온다("촤라락").
  - 닫힘 80% 에서 가운데에 부딪혀 한 번 되튀었다 돌아온다("쾅").
  - 움직이는 동안은 날개가 레일 안에서 덜컹거린다. 가린 범위는 1(왼쪽 절반)을 넘지 않는다.
- **소리**: `art/audio/sfx.gd` 의 `shutter`. 촤라락 딸깍이 점점 촘촘해지다가 0.31초에 쾅이 나는 합성음이다. 열릴 때는 높고 작게 난다.
- **F5**: `DartMachine.show_chaos` 가 방장 모양(`BoardChaos.shutter_amount`) 값을 그대로 넘긴다. 판정(왼쪽 절반 0점)은 바꾸지 않았다.
- **F6 카드 라운드**:
  - 예전에는 "가림판" 판자(`CoverPlank`)를 보였다.
  - 지금은 `turn_effects._show_cover` 가 `DartMachine.slide_shutter(closed)` 를 부르고, 머신이 스스로 여닫는다.
  - 닫을 때는 판정과 같은 곡선을 쓰고, 열 때는 F5 와 같은 속도로 연다.
  - 판자는 머신이 없을 때만 쓰는 예비다.
