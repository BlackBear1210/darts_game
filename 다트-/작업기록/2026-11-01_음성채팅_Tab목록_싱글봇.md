# 2026-11-01 — 음성 채팅 · Tab 플레이어 목록 · 싱글 플레이 봇 어울리기

## 요청

- ESC 설정에 음성 채팅: 눌러서 말하기 / 음성 감지 중 고르기, 다른 게임처럼 마이크·스피커·음량·감도 설정.
- 말할 때 캐릭터 머리 옆에 스피커 표시.
- 아무 기능이 없던 Tab: 방에 누가 있는지 보여 주고, 다른 사람 목소리 볼륨을 사람마다 조절.
- 멀티플레이에서 마이크가 실제로 되는지 직접 확인(확인용으로 쓴 파일은 올리지 않는다).
- 싱글 플레이: 봇이 앞으로 나와 방해하고, 카드 라운드에 감정표현으로 떠들고, 사람이 못 던지거나 당하면 놀린다(비틱) → 혼자 해도 같이 하는 느낌.

## 만든 것

### 1. 음성 채팅 (`network/voice_chat.gd`, 새 파일)

- `NetworkSession` 아래 노드 `VoiceChat`(화면 전환에도 유지). 방장이 중계하는 구조라 전용 서버·방장 겸 선수 둘 다 같은 길이다.
- 마이크 → 16 kHz 모노로 줄임 → μ-law 8비트(G.711) → 40 ms(640 샘플 = 640 바이트) 묶음. 사람 한 명 약 16 KB/s.
- 보내기: 손님 → 방장 `_voice_up`(unreliable_ordered, 채널 3 — 이동·게임 메시지와 따로). 방장이 확인한다:
  같은 방 사람인지, 봇이 아닌지, 묶음 크기 ≤ 1280 바이트, 초당 보낼 수 있는 양(정상의 2배) 안인지.
  통과하면 방장이 `_voice_down`(authority)으로 같은 방의 다른 사람에게만 보낸다. 방장이 선수면 방장 화면에서 바로 재생.
- 받기: 말하는 사람마다 `AudioStreamPlayer` + `AudioStreamGenerator`(16 kHz) 하나, 버스 `Voice`(코드로 만듦 → Master).
  끊김 방지로 처음 0.08초 모아서 재생하고, 0.4초보다 밀리면 버린다(지연이 쌓이지 않게).
- 마이크는 필요할 때만 연다: 음성 채팅이 켜져 있고, 화면 있는 실행이고, (설정 창의 마이크 검사 중이거나 방에 다른 사람이 있을 때). 혼자 하는 싱글 플레이에서는 안 연다.
- 말하기 방식
  - **눌러서 말하기**(기본): V / Caps Lock / 마우스 뒤로·앞으로 버튼. 글자 입력 칸에 커서가 있으면 무시.
  - **음성 감지**: 소리 크기(dB)가 감도 문턱을 넘으면 보내고 0.4초 더 잡아 둔다. 감도 0~100% → 문턱 -18 ~ -58 dBFS.
- `project.godot` 에 `[audio] driver/enable_input=true` 추가(이게 없으면 Godot 가 마이크를 못 연다).

### 2. ESC 설정 → 음성 채팅 칸 (`ui/settings_panel.gd`, `ui/player_preferences.gd`)

- 음성 채팅 사용 · 말하기 방식 · 눌러서 말하기 키(또는 음성 감지 감도) · 마이크 장치 · 스피커/헤드셋 · 마이크 음량 0~200% · 다른 사람 목소리 0~150% · 마이크 검사 막대 · 내 목소리 들어보기.
- 마이크 검사 막대: 설정 창이 열려 있는 동안 실제 마이크 크기를 보여 준다. 음성 감지면 금색 선 = 문턱, 막대가 민트색이면 지금 보내지는 크기.
- 장치 이름이 긴 경우(예: "마이크 배열(디지털 마이크용 인텔® …)") 선택 칸이 늘어나지 않게 너비 300px 고정 + 글자 자르기(`_device_select`).
- 저장: `user://player_preferences.cfg` 의 `[voice]` 칸(사람마다 볼륨·음소거는 표시 이름 기준 `people`).

### 3. 머리 옆 스피커 (`game/player/player.gd`, `ui/ui_icon.gd`)

- 말하는 동안 캐릭터 머리 왼쪽 옆에 스피커 그림(빌보드), 목소리 크기에 따라 살짝 커졌다 작아진다. 말을 멈추면 0.3초 뒤 사라진다.
- 감정 말풍선과 같은 규칙으로 그 사람 본인 화면에는 안 보인다(자리 레이어).

### 4. Tab 플레이어 목록 (`ui/player_list.gd`, 새 파일)

- **누르고 있는 동안** 보이고 떼면 닫힌다. **짧게 한 번** 누르면 고정되고 마우스가 풀려 볼륨 막대를 끌 수 있다(Tab / Esc 로 닫기).
- 줄마다: 자리 색 이름 · 나/방장/봇 표시 · 점수 · 핑(손님은 방장까지 왕복 ms) · 말하는 중 스피커 · 다른 사람 목소리 0~200% · 음소거.
- 무효(×0) 카드를 꺼내 들고 막을 사람이 둘 이상일 때만 Tab 은 예전처럼 "대상 바꾸기"다(`LoungeHUD.tab_picks_target()`).
- 아래 키 안내에 `Tab 플레이어` · 눌러서 말하기 키 · 말하는 중 표시를 넣었다.

### 5. 싱글 플레이 봇 어울리기 (`game/player/bot_social.gd`, 새 파일)

싱글 플레이(방 설정 `solo`)의 방장에서만 돈다. 멀티 봇 행동·규칙·네트워크 메시지는 그대로다.

- **방해**: 사람 차례마다 60% 확률로 봇 하나가 일어나 레인 옆(구경·방해 자리)으로 걸어 나와 던지는 사람을 보며 점프하고 놀린다. 차례가 끝나면 자리로 돌아간다.
  캐릭터는 다트 판정 레이어에 없어서 다트는 그대로 꽂힌다(방해는 눈으로만). 봇이 레인 벽 끝에 걸리지 않게 `BotDriver` 에 벽 끝을 돌아가는 길을 넣었다.
- **수다**: 카드 충전 라운드(85%)·테이블 집합(50%)에 봇끼리 감정표현을 주고받고, 가끔 사람에게도 보낸다. 말할 때 상대 쪽으로 고개를 돌린다.
- **비틱**: 사람이 빗나가면(0점) 또는 카드·병·캡슐에 당하면 봇 한둘이 사람을 보며 ㅋㅋㅋ·메롱 + 팔 번쩍(카드를 쓴 봇이 먼저). 방해 중인 봇은 바로 뛴다.
- **반응**: 사람이 잘 맞히면 가끔 칭찬(헉·최고), 봇 자신이 잘하면 자랑, 빗나가면 흑흑. 사람이 감정을 보내면 75% 확률로 봇이 답한다. 경기가 끝나면 이긴 봇은 메롱, 나머지는 GG·최고.
- 감정 두 개 추가: 6 좋아해, 7 GG(`Emotes.LOVE`, `Emotes.GG`). 봇 감정도 사람과 같은 1초 간격 검사를 지난다.

- **멀티플레이 음성(임시 검사, 저장소에 안 올림)** — 실제 ENet 방장 1 + 손님 2, 마이크 대신 사인파를 `VoiceChat.feed()` 에 넣음:
  1. 손님1 목소리 → 방장·손님2 모두 들림(방장 중계), 말한 사람은 자기 소리를 안 받음.
  2. 방장 목소리 → 손님 둘 다 들림.
  3. 눌러서 말하기에서 키를 안 누르면 아무도 못 들음(마이크 막대는 움직임).
  4. 크기 상한(1280 B)을 넘는 가짜 묶음은 방장이 버림. 손님이 방장 전용 `_voice_down` 을 남의 이름으로 부르면 엔진이 거부(`RPC '_voice_down' is not allowed ... authority is 1`).
  5. 사람별 음소거 → 재생 -80 dB, 볼륨 150% → +3.5 dB.
  6. 경기 화면으로 넘어가도 음성 이어짐 + 방장·손님2 화면에서 손님1 머리 옆 스피커 표시, 말을 멈추면 사라짐.
  7. 음성 채팅을 끈 사람 화면에서는 재생 안 함.
  8. 나간 사람의 재생기는 방장에서 지워짐.
- **실제 마이크**: 화면 없는 방장 + 창 모드 손님. 손님이 노트북 마이크(인텔 스마트 사운드 마이크 배열, 48 kHz)를 열고 읽은 소리가 방장에게 도착(감도 100%·음량 200% 조건의 방 소리 크기 막대 0.47).

## 확인 못 한 것

- `run_dedicated.py` 는 내보낸 서버·클라이언트 실행 파일이 있어야 돌아서 이번에 돌리지 않았다.
- 서로 다른 PC 두 대 이상에서 사람이 실제로 말하고 듣는 음질·지연·에코(헤드셋 없이 스피커로 들으면 상대 소리가 다시 마이크로 들어갈 수 있다 — 에코 제거는 없다).
- 봇 방해·비틱이 "같이 하는 느낌"이 드는지, 너무 시끄럽지 않은지(사람 손맛).
- 음성은 녹음·저장하지 않는다. 방장만 소리를 중계하고 내용을 보지 않는다(검사는 크기·속도뿐).

## 다음 사람에게

- `VoiceChat` 은 `class_name` 이 없다. 에디터가 새 클래스를 훑기 전에도 돌게 각 파일에서 `const VoiceChat = preload("res://network/voice_chat.gd")` 로 쓴다.
- 화면 없는 실행은 마이크가 없다(dummy 오디오). 시험은 `VoiceChat.feed(frames, rate)` 로 소리를 넣는다.
- 봇 어울리기 확률·간격은 `bot_social.gd` 맨 위 상수. 싱글에서 방해 봇 위치는 `HECKLE_SIDE`/`HECKLE_DEPTH`.
