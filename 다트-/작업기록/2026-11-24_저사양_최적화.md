# 2026-11-24 · 저사양 최적화 2차 — 묶은 원본 제거 · 그림자 패스 정리

사용자 요청: "저사양에서 렉걸린대서 최적화를 좀 해봐야할거같아".
2026-11-23 훑어보기에서 찾아 두고 아직 안 손댔던 두 가지를 했다(로비 배경은 그때 이미 고쳤다).

## 1. 묶은 원본을 숨기지 말고 지운다 (`art/static_batch.gd`)

`StaticBatch` 는 정적 메시를 재질·격자별로 합친 뒤 **원본을 `hide()` 만 했다.**
숨겨도 노드는 트리에 남아 매 프레임 순회 대상이고 렌더 서버에도 인스턴스가 남는다 — 경기 화면에 568개였다.

이제 **자식이 없는 원본은 `queue_free()`** 한다. 자식이 달린 원본만 숨긴 채 남긴다 —
지우면 묶기에서 빠진 자식(움직이는 소품·얼굴 부품)까지 사라지기 때문이다.

묶은 뒤에 묶음 하나만 되돌리는 길은 **원래도 없었다**(코드 주석에 그렇게 적혀 있다).
방 일부를 빼야 하면 `TableView.rebuild_pub` 이 씬 파일에서 통째로 다시 만든다 → 지워도 안전하다.

## 2. 그림자를 만들지 않는 메시는 그림자 패스에서 뺀다 (`game/table/table.gd`)

방에서 **그림자를 만드는 조명은 둘뿐**이다 — 카드 테이블 펜던트(전방향)와 과녁 스포트(사정거리 5.5m).
그런데 메시 2,122개가 전부 `cast_shadow` 켜짐이었다.

`trim_shadow_casters()` 가 묶기 직후에 두 가지로 끈다.

- **사정거리 밖**: 어느 그림자 조명의 사정거리에도 닿지 않는 메시.
  그림자를 만드는 `DirectionalLight3D`(해)가 있으면 방 전체가 사정거리 안이므로 거리로는 아무것도 끄지 않는다.
- **너무 작은 것**: `SHADOW_MIN_SIZE`(0.2m)보다 작은 소품. 어두운 펍에서 20cm 물건의 그림자는 보이지 않는데
  그림자 패스에는 큰 벽과 똑같이 한 번씩 올라간다. 다트머신 부품의 49%, 방 소품의 22% 가 여기 해당한다.

## 3. 잰 값 (1280×720 · 라운지 4인 방 · RTX 4070 SUPER)

| | 전 | 후 |

| 경기 화면 노드 | 3,335 | **2,884** |
| 메시 | 2,505 | **2,053** |
| 묶기로 숨긴 채 남은 원본 | 568 | **103** |

**화면은 똑같다.** 같은 구도로 전/후를 찍어 비교했다(`.godot/check_opt.gd`) — 사라진 그림자가 눈에 띄지 않는다.

### 프레임 시간은 이 PC 에서 거의 안 움직였다

투척선 1인칭 구도에서 **3.13ms → 3.07ms**. 측정 잡음과 같은 크기다. 솔직히 이 기계에서는 이득을 증명하지 못했다.
이유는 둘이다. (1) 이 GPU 가 병목에서 한참 멀다. (2) 엔진이 이미 조명 절두체로 그림자 패스를 걸러서,
"사정거리 밖" 메시는 원래도 그림자 맵에 안 그려지고 있었다 — 줄어든 것은 그 판정 비용과 노드 순회 비용이다.

**저사양에서는 사정이 다르다.** 노드·메시 수는 CPU(순회·컬링), 그림자 캐스터 수는 GPU(그림자 맵 채우기)에 직접 붙는 값이고
둘 다 약한 기계일수록 비싸진다. 다만 그건 **이 기계에서 재지 못했다.**

## 4. 함께 확인한 것 — "그래픽 품질" 옵션은 이미 제대로 작동한다

2026-11-23 에 "가벼움이 효과 없다"고 적었는데, **GPU 시간만 따로 재 보니 틀린 말이었다.**
그때는 전체 프레임 시간을 봐서 CPU 쪽에 묻혔던 것이다(`RenderingServer.viewport_get_measured_render_time_gpu`).

1920×1080 · 240프레임 평균 · 두 번 반복:

| 품질 | 해상도 배율 | GPU 시간 |
| --- | --- | --- |
| 높음 | 1.00 | 1.124 / 1.019 ms |
| 기본 | 0.85 | 0.740 / 0.652 ms |
| 가벼움 | 0.65 | 0.484 / 0.454 ms |

**높음 → 가벼움 이 GPU 시간 −55%.** 저사양에서 제일 먼저 내려 볼 값이 맞다.

### 그림자를 끄는 선택지는 넣지 않았다

"가벼움에서 그림자도 끄기"를 만들어 재 봤더니 **해상도만 0.65 로 낮추고 그림자를 켠 경우 0.459 / 0.507ms** 로
가벼움(0.484 / 0.454ms)과 **차이가 없었다.** 위 2번에서 그림자 캐스터를 58% 줄인 뒤라 그림자가 이미 싸졌기 때문이다.
측정으로 이득이 없는데 화면만 나빠지므로 그 변경은 되돌렸다.
