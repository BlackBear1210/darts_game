# 승인 캐릭터 전체 모션 외형 검수

승인 원본 BLEND와 GLB의 SHA-256을 대조했다. 게임용 수정 전·후 모델의 기본 정점, 삼각형 인덱스, 법선, UV, 재질, 텍스처와 뼈의 기본 변환이 일치한다. 몸과 반팔의 스킨 가중치도 일치한다. 바짓단과 신발에서만 가중치를 손봤다.

- 어깨와 목의 과도한 회전을 제한하고, 팔꿈치의 굽힘 평면을 보존하면서 손과 아래팔을 옷 밖에 놓는다. 조준할 때 손목이 과도하게 접히는 자세도 제한한다.
- 웅크려 걷기에서 셔츠 밑단과 바지 허리가 교차하지 않도록 골반 기울기와 발 접지를 맞췄다. 춤에서 한쪽 신발이 반대쪽 바짓단을 지나거나 갑자기 옆으로 튀던 구간을 정리했다. 댄스 02에서 손이 몸통 옆을 돌아 앞으로 나오는 두 키를 연결했다.
- 넘어짐에서는 실제 가슴과 양발에 물리 조각을 두고, 옆으로 쓰러진 동안 다리가 배 쪽으로 접히는 문제를 보정했다. 경기 결과와 상태 메시지를 결정하는 네트워크 코드는 이번 변경에서 다루지 않았다.

## 결과와 재현

프로젝트 상위의 `output/character_nude_base_20261116/motion_review_20261119`에 검수 결과가 있다.

| 자료 | 위치 |
|---|---|
| 최종 메시·원본 클립 동일성 검사 | `checked/asset_audit.json` |
| 최종 클립 27개 + 서기·착석 상태 40조합, 24fps에서 6,010개 자세의 6개 부품 쌍 | `checked/collision_audit.json` |
| 앞·뒤·좌·우 넘어짐과 회복, 실제 물리 프레임 168개 | `ragdoll_side/collision_audit.json` |
| 충돌이 재현됐던 이전 물리 자세 291개에 새 보정을 적용한 결과 | `side_repro/collision_audit.json` |
| 실제 펍에서 정면·측면·후면으로 촬영한 검수 자세와 움직임 | `checked/game_frames`, `checked/motion_game.gif` |
| 게임의 이동과 착석 함수를 호출해 촬영한 화면과 1인칭 시점 | `checked/live` |

최종 6,010개 중 직전 전수검사와 스킨 및 모든 뼈 행렬이 바이트 단위로 같은 자세는 6,004개다. 바뀐 6개는 별도로 삼각형 교차를 재검사했다. 모든 샘플에서 몸·옷, 옷·옷 사이를 통과하는 삼각형 쌍은 0개였다. 이는 현재 옷차림과 기록된 시점의 결과다. 손가락별 쥐기 가중치는 기존 리그 사양이다.

게임 모델 재생성에는 저장소 상위의 `character_assets/approved_game_character_20261119/build_game_character.py`와 같은 폴더의 캐시를 쓴다. 생성 중 저장되는 `character_game_source.blend`는 GLB 후처리 직전의 중간 파일이다. 새 게임 모델을 검사하려면 Godot에서 `res://tests/inspect_character_motions.gd -- <새폴더명>`을 실행한 뒤 검수 결과 폴더의 `run_collision_workers.py <새폴더명>`를 실행한다. `res://tests/inspect_character_ragdoll.gd`는 실제 경기에서 네 방향 물리 동작을 기록한다.

실제 호스트·클라이언트의 7개 감정표현 재생, 중단, 이동 중 전환과 자연 종료가 통과했다. 4인 별도 경기 검사는 원격 점프·이동 정지 직후 참가자 간 위치 차이가 12cm 미만이어야 하는 조건에서 두 차례 실패했다. 같은 조건으로 다시 실행해 5라운드와 재경기를 통과했다. 직전 실행의 위치 오차 원인은 특정하지 않았다.
