# 작업 기록

이 폴더의 기준 경로는 `다트-/작업기록/`이다.

- `CURRENT_TASK.md`: 현재 작업의 범위·진행 상태.
- `HANDOFF.md`: 다음 작업자가 알아야 할 변경·검증·남은 문제. 최신 기록을 위에 쓴다.
- 개별 작업 기록: `YYYY-MM-DD_작업명.md`. 팀원이 동시에 작업할 때는 서로 다른 파일을 사용한다.

개발 규칙은 [AGENTS.md](../AGENTS.md), 현재 설계는 [ARCHITECTURE.md](../docs/ARCHITECTURE.md)에 둔다.
작업 기록을 근거로 공통 규칙이나 설계를 임의로 바꾸지 않는다.
