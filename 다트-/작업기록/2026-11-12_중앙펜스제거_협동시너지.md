# 중앙 펜스 제거·동일 카드 협동 시너지 — 2026-11-12

사용자 요청: 중앙 펜스를 완전히 없애고 여러 사람이 같은 방해카드를 쓸 때 시너지를 추가. 후속 답변으로 서로 다른 2/3인의 협동 단계를 승인했다. 아래 수치는 먼저 플레이할 기본값이며 팀 밸런스 조정 대상이다.

## 맵

- F5 공용 맵의 중앙 로프·기둥·출입 금지 표지와 레이어 4 충돌벽 6개를 제거했다. 바닥 매트·투척선은 유지한다.
- `GameRoomBuilder`에서 제거하고 `pub_builder.gd -- --game-room-only`로 `pub_game.tscn`을 재생성했다. 저장된 씬을 손으로 고치지 않았다. 이 경로는 캐릭터·쇼케이스 생성물을 다시 쓰지 않는다.
- 투척선 앞 다트 홀 전체에서 몸과 궤적이 실제 교차하면 다트를 막는다. 투척선 뒤 대기 인원은 계속 제외한다. 기존 `BLOCK_ZONE`은 봇 선호 위치에만 남긴다.
- F6 시연에는 별도 좌표의 투척 보호 구역이 있다. 이번 F5 공용 맵 변경과 별개이며 기존 경계 집행을 유지한다.

## 협동 규칙

- 대상: 상대 지정 방해카드 16종(과녁 11·피지컬 4·무게 증가). 연산·특수·자기 강화 카드에 별도 시너지를 붙이지 않는다.
- 동일 투척자에게 같은 종류를 서로 다른 2명이 사용하면 1.5배, 3명이 사용하면 2배 단계. 최대 3명.
- 같은 사람은 같은 효과의 현재 지속 범위에서 한 번만 참여한다. 재사용은 손패를 소비하지 않고 이유를 표시한다. 차례 효과는 차례 종료, 점수 고정은 라운드 종료에 초기화한다.
- 기존 효과를 끝남으로 기록하고 기여자 목록을 가진 강화 효과 하나로 합친다. 따라서 중첩 합산·역방향 상쇄·강도 중복 계산이 없다.
- 시너지 참여자는 실제 요청 발신자로 확정한다. 공개 상태에는 실제 peer ID 목록·인원·배율이 포함되며 클라이언트는 이를 읽기만 한다.
- HUD와 카드 피드에 인원/배율을 표시하고 다른 사람이 이미 쓴 카드를 들면 다음 협동 단계 안내를 표시한다.

| 카드 | 2인 | 3인 |
| --- | --- | --- |
| 무게 증가·바람·졸림·어지러움 | 낙하/밀림/오차/기울기 1.5배 | 2배 |
| 과녁 회전 | 각속도 1.5배 | 2배 |
| 피자·세로·가로 분리 | 이동 거리 1.5배 | 2배 |
| 과녁 이동 | 왕복 진폭 1.5배 | 2배 |
| 셔터 | 1.2초마다 좌우 교대 | 0.6초마다 교대 |
| 조작 반전 | 양축 반전 | 양축 반전+감도 1.35배 |
| 숫자 섞기 | 중복 숫자 허용 | 중복 숫자+숫자 5개 먹물 |
| 점수 랜덤 변경 | 숫자·불의 추첨 상한 1.5배 | 2배 |
| 점수 고정 | 추가 고정 구역 수 1.5배 | 2배 |
| 봉쇄 구역 | 선택 칸+시계 방향 이웃 | 선택 칸+양쪽 이웃 |
| 먹물 얼룩 | 총 8칸 | 총 10칸 |

- 바람 방향은 첫 사용의 방향을 유지한다. 졸림은 비행 중 강화해도 기존 발사 오차를 재추첨하지 않고 배율만 올린다.
- 움직인 그림과 방장 채점, 원격 그림, F6가 공용 `BoardChaos.boost`를 사용한다. 값 변화도 공용 `BoardLayout.apply_card_change`에서 처리한다.
