# 2026-10-31 — 앉은 시점 · A/D 엿보기 · 무효 한 장 · 마시기 몸짓 · 유리병 파편

- 작업자 / 브랜치: 김도형(디자인) + Claude / `dev_1`. 같은 날 다른 작업자 커밋 `972714c`(카드 턴 없애고 다트 턴 중 카드 사용 · 상호작용 키 F) 위에서 했다.
- 상태: 자동 검증 PASS(아래 표), **미커밋**. 사람이 직접 하는 손맛(기울이기 멀미·속도)·실제 여러 PC 화면은 미검증.

## 왜

사용자 요청(스크린샷 첨부):

1. 앉으면 테이블이 눈높이라 매트 위 카드가 안 보인다 → 테이블이 시야 아래에 깔려야 한다.
2. A·D 는 레인보우 식스 시즈 Q·E 기울이기처럼 **머리를 좌우로 내밀어 옆 사람 카드를 훔쳐보고 견제**하는 것인데, 지금은 의자에서 옆으로 미끄러지기만 한다.
3. 무효(×0)가 너무 자주 나온다 → **한 경기에 딱 한 장**.
4. 음료 마시는 행동이 없다 → 마시는 애니메이션.
5. 병이 깨지면 네모 조각이 떨어진다 → 실제 유리병처럼 파편으로.
6. 전체 디자인 개선 · 바뀐 코드에 주석.

## 함정

- 엿보기 판정은 **눈 위치가 아니라 자리 위치**에서 잰다. 기울어서 눈이 옆으로 나가면 옆자리 매트가 거의 정면에 놓여 판정이 흔들렸다(첫 화면 시험 실패 원인).
- `pub_game.tscn` 은 생성물이다. `game_room_builder.gd` 를 고치면 `pub_builder.gd` 를 다시 돌려야 화면에 반영된다(안 돌리면 옛 크림색 카드 상자가 새 카드와 겹쳐 보인다).
- 카드 그림(`CardFaces`)은 굽기(bake)가 끝난 뒤에 만들어야 한다. `seat_cards` 는 `GameView._prepare_hand_fan` 의 굽기 뒤에 붙인다.
- 새 스크립트 4개(`seat_cards.gd`, `glass_shards.gd`, `render_seat_peek.gd`, `test_nullify_limit.gd`)의 `.uid` 파일은 아직 없다. 에디터가 다시 훑으면 생기니 **커밋할 때 함께** 넣는다.
- F6 카드 라운드 시연의 무효 확률(`round_rules.gd`)은 바꾸지 않았다(F5 경기만 한 장).

## 미검증 / 남은 작업

- 사람이 직접 A·D 를 눌렀을 때 멀미·속도·각도 손맛. 숫자는 위 표에서 조절.
- 실제 여러 PC 에서 남의 기울기·마시기·유리 파편이 같은 박자로 보이는지(자동 시험은 상태 동기화만 본다).
- 1인칭 마시기 병은 화면 오른쪽 아래에서 병목이 얼굴로 오는 모습이다. 병 바닥이 하늘로 들리는 연출을 원하면 `FIRST_PERSON_MOUTH`·`DRINK_TIP` 조절.
- 엿보기를 막는 수단(카드 가리기 등)은 없다 — 견제 규칙은 팀 논의 후보.
