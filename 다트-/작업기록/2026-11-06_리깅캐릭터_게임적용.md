# 2026-11-06 리깅 캐릭터(v18) 게임 적용

- 작업자 / 브랜치: Claude Code / `dev_1`
- 요청: "animated_base_v18에 있는거 게임에 적용시켜. 각 모션들도 있는데 모션에 맞게 잘 적용시켜. 봇들도 현재 만든 캐릭터로 다 교체해."

## 바뀐 것

플레이어와 봇 네 자리가 모두 v18 캐릭터로 바뀌었다. 로비의 던지는 사람과 벌칙 원판에 묶이는 사람도 같은 캐릭터다.
펍 손님·바텐더는 요청 범위(봇)가 아니어서 예전 모델 그대로다.

- `art/characters/rigged/character_library.glb`: v18 + 게임 모션. 옷·머리 조각이 다 들어 있다.
- `art/characters/rigged/player_character.tscn`: 위 GLB 를 상속해 기본 차림만 보이게 둔 씬. 게임이 쓰는 파일이고 에디터 3D 화면에서도 같은 모습으로 보인다.
- `art/player_look.gd`: `character(seat)` 이 GLB 를 만들고 셔츠를 자리 색으로 칠한다.
- `art/characters/character_motion.gd`: `CharacterRig` 와 같은 겉면(`animate`, `play_throw`, `holding_cards` …)으로 모션을 고른다.
- `art/characters/character_pose_layer.gd`: 온몸 모션 위에 팔·고개·기울기·왕머리를 얹는다.
- 캐릭터 정면이 `-Z` 로 바뀌어 `PlayerView` 의 180도 회전을 없앴다. 로비와 원판은 반대로 돌려 맞췄다.
- 카드 부채는 `Model/Body` 대신 캐릭터 자식이고, 위치는 매 프레임 `Socket_Card_L` 을 따라간다. 방향은 몸 기준 고정이다.
- 예전 막대 손가락(`PointFinger`)은 없앴다. 이제 진짜 손가락으로 가리킨다.

## 만들면서 고친 것

- **소매가 뾰족해졌다**: v18 셔츠의 소매 끝 꼭짓점 일부가 `spine` 을 따라가 팔을 들면 몸 쪽에 남았다. v19 복사본에서만 그 몫을 윗팔로 옮겼다.
- **부채가 누웠다**: 눈을 곧바로 보게 하면 손이 눈 바로 아래라 수평에 가까워진다. 앉으면 몸이 기울어 더 심했다. 몸 기준 고정 방향으로 세웠다.
- **깜빡일 때 눈이 검게 뚫렸다**: 눈을 납작하게 누르면 뒤 눈구멍이 드러난다. 눈꺼풀이 없어 감는 동안 흰자를 피부색으로 칠하고 눈동자를 숨긴다.
- **`remove_immutable_tracks`**: 켜 두면 기본 자세와 같은 뼈 트랙이 빠져 모션을 섞을 때 앞 모션 자세가 남을 수 있어 `.import` 에서 껐다.
- 모디파이어 결과는 `get_bone_global_pose` 로 읽히지 않는다(프레임 끝에 되돌린다). 시험은 뼈에 붙은 `BoneAttachment3D`(`hand_L`, `hand_R`, `head`)로 잰다.

## 알려진 차이·남은 판단

- 1인칭 손은 예전 벙어리장갑(`CharacterFactory.create_hand`) 그대로다. 3인칭 손과 모양이 다르다.
- 펍 손님·바텐더는 예전 모델이다. 같은 방에 그림체가 둘이다.
- 캐릭터 키가 약 1.85m 다. 충돌 캡슐 1.7m, 몸 맞음 판정 윗면 1.75m 는 그대로라 머리끝은 판정 밖이다.
- 숙였을 때 눈높이 약 1.09m 로, 1인칭 카메라 0.95m 보다 높다. 숙인 캡슐(약 1m)보다 머리가 위로 나온다.
- 걷기는 속도 3.8m/s 에 비해 보폭이 작아 발이 조금 미끄러진다. 전용 달리기 클립이 있으면 해결된다.
- 던지기는 v18 클립대로 아래팔 위주라 정면에서는 움직임이 작게 보인다.
- git 에 올린 캐릭터 파일은 게임이 쓰는 `art/characters/rigged/` 와, GLB 를 다시 만드는 데 필요한 v18 `character_animated.blend`·목록 파일, `game_ready_v19/build_game_motions.py` 뿐이다. 나머지 버전 폴더와 v18 의 캐시·영상·중복 GLB 는 이 PC 에만 있다.
