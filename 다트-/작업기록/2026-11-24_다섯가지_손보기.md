# 2026-11-24 · 구역 지정 팝업 · 다트판 높이 · 차례 표시 · 벌칙 속도 · 포물선

사용자 요청 다섯 가지를 한 번에 손봤다.

## 1. 구역 지정은 다트판 팝업에서 클릭으로

예전에는 Z·X 로 20칸을 하나씩 넘겨야 했다. 이제 구역 카드를 꺼내 들면 **다트판이 팝업으로 뜨고 눌러서 고른다**.

- 새 파일 `ui/sector_picker.gd`. 20칸을 그리고 마우스를 올린 칸을 강조한다. 숫자는 **지금 판의 숫자**를 받아 그린다
  (카드로 섞여 있을 수 있다). 칸 번호 약속은 `BoardLayout.sector_at` 과 같다 — 0번이 12시, 시계 방향.
- 띄우는 동안 마우스를 풀고(`MOUSE_MODE_VISIBLE`) 닫으면 다시 잡는다. 오른쪽 버튼·Esc 로 닫는다.
- Z·X 로 넘기는 길은 그대로 남겼다 — 홀짝·정밀 조정처럼 판이 필요 없는 카드가 쓴다.
- **그림은 팝업 한 곳(`_draw`)에서 그린다.** 처음에는 자식 Control 의 `draw` 신호로 나눠 그렸는데
  다시 그리기 타이밍이 어긋나 강조가 안 나왔고, 어둡게 덮는 막을 자식 `ColorRect` 로 두니 그림 위를 덮었다.

### 폭탄(지뢰 심기)

- `mine` 카드에 `"choice": "sector"` 를 줘서 **무작위가 아니라 고른 칸**에 심는다.
- 팝업에서 **마우스 포인터가 폭탄으로 바뀐다**(심지와 불꽃까지 그린다).
- **같은 칸에 겹쳐 심을 수 있다.** `MatchCards.landing_points` 가 `mines.count(칸)` 으로 세므로
  2겹이면 벌점도 2배(−15 → −30)다. 예전에는 `in` 으로 봐서 몇 겹이든 한 번만 터졌다.
- 지뢰는 자기 차례가 아닐 때 쓰는 카드라 "조준 중일 때만" 규칙에서 뺐다(`MatchCardActions.check`).

## 2. 다트판을 조금 내렸다

`DartMachine.BOARD_Y` **2.9 → 2.6m**. 눈높이 1.65m 에서 너무 올려다봐야 했다.
`TableView.BOARD_CENTER` 가 이 값을 쓰므로 `layout_signature` 가 바뀐다 → `pub_builder.gd -- --game-room-only` 로 방 그림을 다시 만들었다.

## 3. 내 차례를 크게 알린다

`ui/lounge_hud.gd` 에 차례 팝업을 더했다. 차례가 시작되면 화면 위쪽 1/3 에 **"내 차례!"** 가
자기 자리 색으로 커지며 뜨고 2.2초 뒤 사라진다. 아래 줄에 남은 발수와 조작을 적는다.
조준점과 아래 키 안내를 가리지 않는 자리다. 차례마다 한 번만 뜬다(`turn_id` 로 거른다).

## 4. 벌칙 원판을 빠르게

`PUNISH_SPIN_SPEED` 1.1 → **2.0** 라디안/초(한 바퀴 5.7초 → **3.1초**).
`PUNISH_SPIN_ACCEL` 2.2 → 4.0 으로 같이 올려 방향 전환이 1초 안에 끝난다 —
다트 비행(0.4초)보다는 길어서 날아오는 걸 보고 홱 피하지는 못한다(그 균형은 그대로다).

## 5. 더 포물선으로

`DartConfig.gravity` 9.8 → **14.0**. 방장이 도착 시각을 맞춰 위로 던지므로(`initial_velocity`)
중력이 클수록 **같은 자리에 꽂히면서 더 높이 솟는다**.

7.26m 거리에서 계산한 값(`.godot/check_arc.gd`):

| 중력 | 꽉 충전: 직선보다 솟음 | 70% 충전 착탄 | 40% 충전 착탄 |
| --- | --- | --- | --- |
| 9.8 (전) | +0.25m | −0.25m | −0.78m |
| **14.0 (후)** | **+0.36m** | **−0.35m** | −1.11m |
| 18.0 | +0.46m | −0.45m | −1.43m |
| 24.0 | +0.62m | −0.60m | −1.90m |

14 를 고른 이유: 솟음이 44% 커지는데 70% 충전이 아직 판 안이다(점수 원 반지름 0.75m).
