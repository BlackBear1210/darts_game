# 충전 조준점과 다트머신 점수 표시 · 2026-11-28

- ESC → 개인 설정 맨 위에서 십자가·원형과 RGB 색을 고르고 미리 본다. 적용하면 로컬 ConfigFile에 저장한다. 기존 설정에는 크림색 십자가를 쓴다.
- 좌클릭 충전량에 따라 중심 간격은 논리 픽셀 20 → 5.5, 원의 반지름은 20 → 8로 줄어든다. 발사·취소·포커스 이탈 때 원래 크기로 돌아간다. 실제 경기와 카드 라운드 시연이 같은 그리기 코드를 쓴다.
- 머신 왼쪽 영사막에는 좌석 순서로 이름·점수·차례·벌칙을 표시한다. 상단 DARTY 명판 위의 표시기는 투척자 이름과 점수를 함께 보여 주고, 턴이 시작된 2.8초 동안 본인에게 ‘내 차례!’를 띄운다. 오른쪽 판에는 좌·우클릭 투척 안내를 배치했다.
- 점수는 두 화면 모두 같은 7세그먼트 숫자와 소수점·음수 부호로 그린다. 각 2D SubViewport는 표시 내용이 바뀔 때 한 프레임 갱신한다. 차례·판정은 기존 방장 경기 상태를 읽는다.
- 펍 옷장 외부의 걸레받이·허리 몰딩·처마가 만나는 두 모서리에 마감 기둥과 캡을 넣었다. 탈의실 내부도 옆벽까지 징두리와 난간을 이었다. 생성기 변경을 경기용 pub_game.tscn에 반영했다.
- 로비·설정·인게임 HUD에 월넛, 크림, 황동색과 공용 버튼 테두리·그림자를 적용했다. 로비·옷장 3D도 그래픽 품질 설정을 따르며 경기 HUD는 효과가 없을 때 효과 덮개 그리기를 쉰다.
- 종료 시 MatchCards와 MatchCardActions가 서로를 붙잡던 참조를 WeakRef로 바꿨다. 투척 시험의 신호 연결을 실제 경로에 맞추고, 대상 선택 시험 중에는 봇 자동 행동을 멈춘다.

## 검증

- Godot 4.6.3, D3D12 Forward+, GeForce MX450. 로비·개인 설정·옷장 안팎·펍과 오락실 점수판·두 조준점의 충전 전후를 실제 렌더로 확인했다. 임시 프로필에서 사용자 지정 RGB와 원형 선택을 저장하고 다시 읽었다.
- 헤드리스 GDScript 시험 32/32 통과. 전체 스크립트 로드, 투척 입력, 소수·음수 점수, 차례 팝업, 카드, 옷장, 경기 종료 리소스 검사를 포함한다.
- 로컬 다중 프로세스 2·3·4인 방의 시작 조건·공동 입장·재경기·재접속·방장 퇴장, 로딩 장벽과 연결 실패 복구 통과. 한 PC에서 여러 엔진을 처음 띄울 때에만 첫 상태 대기를 최대 90초로 늘렸다. 실제 원격 LAN·인터넷 회선은 미검증.
