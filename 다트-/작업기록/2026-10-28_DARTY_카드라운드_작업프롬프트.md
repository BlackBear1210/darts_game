## 1. 실행하는 법(먼저 읽기)

| 하고 싶은 것 | 방법 |
| --- | --- |
| 카드 라운드 시연 | Godot 에서 `game/card_round/card_round.tscn` 열기 → **F6**(지금 장면 실행). 또는 저장소 최상위 `실행_카드라운드.cmd` |
| 팀 실제 경기(카드 라운드 없음) | **F5**(= `app/main.tscn`, 로그인·로비·네트워크 경기) |

| 화면 캡처 15장 | `godot --path . --script res://tests/test_card_round.gd -- --render` → 저장소 최상위 `output/card_round/` |

### "안 뜬다 / 작업 전 화면 그대로다"의 원인과 해결(2026-10-28)

| 원인 | 해결 |
| --- | --- |
| **F5 는 팀 경기(`app/main.tscn`)** 라 카드 라운드가 안 나온다. 카드 라운드는 F6 전용 | 위 표대로 F6. 메인 장면은 팀 소유라 바꾸지 않았다 |
| 카드 라운드 장면은 모든 것을 **실행할 때 코드로 만든다** → 에디터에서 열면 빈 화면 | `card_round.tscn` 에 **펍 테이블(`game/table/table.tscn`)을 `Table` 노드로 넣었다** → 에디터에서 열면 펍·테이블·다트판이 보인다. 카드·캐릭터·HUD 는 실행하면 생긴다 |
| 바탕화면 `DARTY_프로젝트\DARTY_EDITOR.cmd`·`DARTY_PLAY.cmd` 는 **예전 단독 예제(`darty_godot`)** 를 열었다 | DARTY_프로젝트 정리 때 실행 파일을 이 저장소(`다트-`)를 여는 것으로 바꿨다 |
| 에디터를 연 채로 파일이 바뀌었다 | **에디터를 껐다 다시 열기**(열린 장면을 저장하면 옛 내용으로 덮어쓸 수 있다) |

## 2. 폴더 지도 — `game/card_round/`

한 파일 = 한 가지 일. 감독(`card_round.gd`)은 **순서**만 갖고, 실제 일은 부품이 한다.

```text
game/card_round/
├─ card_round.tscn        장면: Table(펍) · Camera(Hand·Fan) · ThrowController · Players · Darts
├─ card_round.gd          감독: 단계 순서(카드 단계 → 다트 단계 → 라운드 정리 → … → 엔딩·벌칙·골드)와 부품 연결
├─ rules/                 규칙 계산(노드 없음 → 방장 쪽으로 그대로 옮길 수 있다)
│  ├─ round_rules.gd      덱·딜링·꺼내 들기·쓰기·무효·효과 시점·점수 연산·승리 조건 3가지·방해 보상·순위·골드
│  ├─ card_catalog.gd     카드 12종(이름·분류·대상·시점·수치·그림 경로)
│  ├─ bot_brain.gd        봇 카드 판단(꺼내 들기·허세·무효 대응)
│  └─ dart_solver.gd      다트 비행 판정(F5 와 같은 식 + 사람 몸 캡슐)
├─ cards/                 카드 보이기
│  ├─ card_faces.gd       카드 앞·뒷면 그림 굽기(팀 그림 5장 + 코드 그림 7장)
│  ├─ card_view.gd        3D 카드 한 장(뒤집기·떠오르기·빛·사용 표시 페인트 X/그을림)
│  ├─ table_cards.gd      테이블 위 카드 전부(흩어진 덱·섞기·딜링·공개·7칸·보상 칸)
│  ├─ hand_fan.gd         왼손 카드 부채(캐릭터 손 + 내 1인칭)
│  └─ shuffle_motions.gd  섞기 모션 3가지(리플·마술사·딜러)
├─ fx/                    연출
│  ├─ screen_debuff.gd    내 화면 흐림·졸림 눈꺼풀
│  ├─ voice_fx.gd         합성 목소리·변조(음성 채팅 대신)
│  ├─ stun_stars.gd       머리 위 스턴 별
│  └─ punishment_wheel.gd 벌칙 원판
├─ ui/                    화면 UI(규칙은 모른다)
│  ├─ card_round_hud.gd   점수판·효과 목록·내 카드·안내 줄·배너·알림·설정 창·결과 화면
│  └─ round_tracker.gd    위 가운데 라운드 표시(◆ 카드 · ● 다트)
└─ flow/                  진행 부품(감독이 setup() 으로 넘겨주고 신호로 잇는다)
   ├─ round_context.gd    함께 쓰는 상자(ctx): 장면 노드·규칙·설정·시계(now)·난수·단계(phase)·통계
   ├─ round_settings.gd   설정 저장/불러오기·해석(user://card_round_settings.cfg, 검사 땐 안 씀)
   ├─ player_builder.gd   캐릭터 4명 + 왼손 부채 + 머리 위 글자 만들기
   ├─ seat_mover.gd       앉기·일어나기·걷기·모이기·막으러 따라가기·스턴·튕겨 나가기
   ├─ card_actions.gd     카드 행동(꺼내 들기·내려놓기·쓰기·무효·사용 표시)·부채 맞추기·봇 카드 판단 부르기
   ├─ dart_actions.gd     다트 한 발(카드 효과 → 조준·채점)·벌칙 원판 한 발
   ├─ turn_effects.gd     차례 동안 보이는 효과(숫자 섞기·가림판·바람·졸림) + 맞힌 사람 흐림·변조
   ├─ disruption.gd       몸으로 막기: 봇 출동 결정, 몸 맞음 → 스턴·보상·흐림
   ├─ round_camera.gd     내 카메라(앉은 시점·서 있는 눈높이·전체 보기·잠깐 보기)
   ├─ local_input.gd      내 키보드·마우스 → 부품 행동, 던질 수 있을 때만 투척 입력 켜기
   ├─ hud_presenter.gd    규칙 상태 → 화면 글자(점수판 줄·안내 줄·머리 위 글자·결과 글)
   └─ round_capture.gd    검사용 화면 캡처(게임 진행엔 영향 없음)
```

### 부품끼리 잇는 곳(신호) — `card_round.gd _setup_parts()` 한 곳에 모여 있다

| 보내는 쪽 | 신호 | 받는 쪽 |
| --- | --- | --- |
| `seat_mover` | `local_seated` (내가 앉았다) | `round_camera.face_table` |
| `card_actions` | `turn_effect_added` (던지는 사람에게 "차례 동안" 효과) | `turn_effects.apply` |
| `card_actions` | `card_marked` · `nullified` | `round_capture` |
| `dart_actions` | `score_changed` | `hud_presenter.refresh_labels` |
| `dart_actions` | `body_hit(던진 사람, 맞은 사람)` | `disruption.on_body_hit` |
| `dart_actions` | `wheel_body_hit` | `round_capture` |
| `disruption` | `hit_resolved` | `hud_presenter.refresh_labels` + `round_capture.on_body_hit` |

매 프레임 순서(`_process`): 입력(Shift·Alt) → 봇 카드 판단 → 꺼내 든 카드 맞추기 → 카메라 → 머리 위 글자 → 투척 입력 켜기 → HUD → 차례 효과(변조 목소리).
물리 프레임(`_physics_process`): 자리 이동·걷기 → 내 캐릭터 WASD.

## 5. 오류가 나면 어디부터 보나

| 증상 | 먼저 볼 곳 |
| --- | --- |
| F6 했는데 카드 라운드가 아니라 다른 화면 | 열린 장면이 `card_round.tscn` 인지. F5 는 팀 경기 |
| 에디터에서 장면이 비어 보임 | `card_round.tscn` 에 `Table` 노드가 있는지(펍은 `game/table/table.tscn` → `art/pub/pub_game.tscn`) |
| 테이블 위에 흰 카드 자리표시가 남음 | `card_round.gd _strip_placeholder_cards` (재질 이름 "CardBack" 으로 찾음 — 펍 생성기에서 이름을 바꾸면 같이 바꿀 것) |
| 카드가 안 나눠짐·7장이 아님 | `rules/round_rules.gd deal_plan·empty_slots`, `cards/table_cards.gd deal_card` |
| 1~7 눌러도 안 꺼내짐 | `flow/local_input.gd handle`(설정 창이 열려 있거나 autoplay 면 무시) → `flow/card_actions.gd lift`(`ctx.cards_open` 이 false 면 무시 — 카드 공개 전) |
| F 눌러도 안 써짐 | 오른쪽 아래 카드 패널의 빨간 글(`rules/round_rules.gd use_problem`: 1.2초 대기, 대상 없음) |
| 점수 계산이 이상함 | `rules/round_rules.gd resolve_dart`(곱하기 먼저·더하기 나중·0 아래 없음), `apply_points`(500→0 버스트) |
| 효과가 안 켜짐·안 꺼짐 | `rules/round_rules.gd begin_turn·end_turn·end_round`(효과 상태: 대기→적용 중→끝/무효/만료), 보이는 쪽은 `flow/turn_effects.gd` |
| 가림판·바람이 안 보임 | `flow/turn_effects.gd build_props·apply` |
| 몸 맞기가 너무 잦음/없음 | `flow/disruption.gd DISRUPT_CHANCE`, `flow/seat_mover.gd BLOCK_GAP·knock_aside`, `card_round.gd THROW_THROUGH_CHANCE` |
| 캐릭터가 안 앉음·멈춤 | `flow/seat_mover.gd`(`gather` 는 최대 6초 뒤 순간 이동으로 마무리) |
| 화면 글자·패널이 안 보이거나 넘침 | `ui/card_round_hud.gd`(고정 위치 + CenterContainer. 앵커 프리셋을 쓰면 크기 0 부모에서 밀려남) |
| 카드 그림이 하얗게 바램 | `cards/card_view.gd` 재질(자체 발광 금지) |
| 설정이 저장 안 됨 / 검사 후 설정이 바뀜 | `flow/round_settings.gd persist`(검사는 false 여야 한다) |
| 다티/DARTY 글씨 | 생성기 3곳(`game_room_builder.gd`·`pub_builder.gd`·`pub_parts.gd`) 고친 뒤 `godot --headless --path . --script res://art/pub/pub_builder.gd` |
| 방 그림 경고 "TableView 상수와 다릅니다" | `game/table/table.gd` 상수를 바꿨으면 펍 생성기를 다시 돌린다(test_game_look 이 서명 비교) |
