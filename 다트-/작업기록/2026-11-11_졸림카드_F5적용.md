# F5 졸림 카드 적용 (2026-11-11)

- 작업자 / 브랜치: Codex / dev_1.
- 요청: 졸림 카드에서 F5에 빠진 조준 오차를 적용.
- 상태: 구현 완료, 미커밋. 푸시는 사용자가 보류했다.

## 변경

- 기존 F5는 졸림 눈꺼풀만 표시했고, F6에 있는 발사 오차는 빠져 있었다.
- `game/match/match_controller.gd`: 졸림이 있으면 조준점 각 축에 최대 과녁 반지름의 ±30% 오차를 준다. 방장이 한 발에 한 번 뽑아 `_flight_input.drowsy_offset`에 보관하고, 바람 등으로 비행을 재계산해도 유지한다. 다음 발은 새 오차를 사용한다.
- `game/match/match_cards.gd`: 비행 중 졸림을 사용해도 현재 다트에 적용한다.
- `game/card_round/rules/card_catalog.gd`와 `flow/dart_actions.gd`: F5/F6가 같은 강도 상수를 사용한다. F6의 기존 강도는 유지한다.
- 효과는 현재 투척자에게 차례 동안 적용되며, 화면 효과 OFF는 눈꺼풀만 숨기고 투척 판정에는 영향을 주지 않는다.
- 새 카메라 흔들림을 추가한 작업은 아니다. F6와 동일한 무작위 발사 오차를 연결했다.

## 검증

- Godot 4.6.3, 기존 Forward+/D3D12/Jolt 유지.
- `tests/test_drowsy.gd`: PASS. 실제 카드 사용 경로에서 기본 조준 불변, 졸림 범위, 비행 중 사용, 재계산 시 오차 유지, 바람·졸림 중첩, 차례 종료 해제, 다음 발 재추첨, 화면 효과 OFF를 확인했다.
- `tests/test_script_load.gd`: 151개 스크립트 로드 PASS.
- `tests/test_rules.gd`, `tests/test_throwing.gd`, `tests/test_card_round.gd`: PASS.
- 실제 app/main.tscn의 싱글 펍에서 카드 사용 → 눈꺼풀 표시 → `_accept_throw`의 확정 조준 오차를 확인했다. 화면: `.godot/drowsy/01_actual_f5_eyelids.png`. 정상 UI 전체 조작 대신 검증용 손패·대기 시각을 준비한 자동 재현이다.
- 첫 자동 캡처는 화면 생성 직후 즉시 준비하여 기존 카드 그림 굽기 작업과 화면 교체가 겹쳤다. 최종 재현에서는 초기 렌더 완료 후 진행해 스크립트 오류 없이 종료했다. 검사 도구의 준비 시간도 1.2초 경계보다 0.1초 여유를 줬다.
