# DARTY — 다트를 던져라. 판을 뒤집어라.

Godot **4.6.3.stable.official.7d41c59c4**, GDScript, **Forward+ / D3D12**, **Jolt Physics**.
실제 프로젝트는 이 폴더의 `project.godot`이다. 개발 규칙은 `AGENTS.md`, 협업 위치 규칙은 `docs/COLLABORATION.md`를 따른다.

## F5 시작

F5는 **DARTY 로비**를 연다. 예전 개발자 예시 경기를 자동 실행하지 않는다.
가운데에 싱글·멀티·설정·나가기를 배치했다. 우측 하단 로그인은 계정 서비스 미연결 시 준비 안내를 표시한다.

1. **싱글**: 봇 0~3명, 프리셋, 맵 테마를 선택하고 입장한다. 봇 없이 1인 연습도 가능하다.
2. **멀티**: 방 만들기 또는 초대받은 방 참가. 2~4명, 방 이름, 공개/초대 전용, 비밀번호, 포트, 테마를 정한다.
3. 방장은 `Esc` → 방장 · 게임 설정에서 초대 코드를 확인하고 복사한다.
4. 참가자는 코드를 붙여 넣고 필요한 비밀번호를 입력한다. 주소·포트가 자동으로 채워진다.
5. 각자 색깔 의자로 가서 **F로 앉고 Enter로 참여**한다. 두 손을 들고, 중앙 아래에 참여 인원과 미참여 인원이 표시된다. 전원 참여하면 자동 시작한다.
6. 결과에서 방장이 **한 판 더**를 누르면 맵 대기로 돌아온다. 사람은 다시 Enter로 참여해야 한다.

공개 방은 주소로 접속할 수 있다는 뜻이며 인터넷 방 목록 서비스는 아직 없다. 초대 코드는 IPv4 주소·UDP 포트·방 코드를 담는다. 같은 PC는 `127.0.0.1`, 같은 LAN은 방장 내부 IP를 사용한다. 다른 인터넷망 접속에는 UDP 포트 개방 등이 필요하며 NAT 중계·호스트 이전은 제공하지 않는다. 멀티 대기실은 선택한 최대 인원이 다 차지 않아도 현재 2명 이상이 전원 참여하면 시작한다.

다트는 **다트 홀 안·투척선 뒤**에서 자기 차례에만 던진다. 라운지 자리에서는 던질 수 없다. 100% 충전으로 중앙을 겨누면 불을 맞힌다. 기본 3발이며 차례 시작부터 제한 시간이 흐른다. 봇도 투척선까지 걸어가 같은 판정으로 던지고 돌아온다.

## 방장과 개인 설정

개인 설정: 전체·음악·상호작용 볼륨, 전체 화면, 3D 해상도 품질, HUD 크기 80~130%, 카드 화면 효과, 움직임 줄이기, 감도, 일부 키 변경. `user://player_preferences.cfg`에 저장한다. 시각 효과를 꺼도 카드 점수·스턴 판정은 유지된다.

방장 설정은 Esc의 방장 탭 또는 맵 모니터로 연다. 프리셋 설명을 접거나 펼칠 수 있다.

| 프리셋 | 설정 방향 |
| --- | --- |
| 캐주얼 · 함께 배우기 | 네온 오락실, 사칙연산 카드, 음주·취기 꺼짐 |
| 파티 · 변수가 가득 | 펍, 특수 카드 포함, 약한 취기와 카드 배부 때 음주 |
| 클래식 · 다트에 집중 | 카드 없음, 라운드 누적 점수 |

승리는 라운드 누적 / 목표 먼저 도달 / 정확히 0 카운트다운 중 선택한다. 라운드 1~20, 다트 5~120초, 특수 카드 추첨 확률 0~100%, 테마, 음주 여부·강도 0~3, 카드 받을 때 음주, 소품 사용, 공간 효과음을 조절한다. 경기 중에도 라운드 상한, 다트 제한 시간, 특수 카드 확률을 바꿀 수 있다. 라운드 상한은 현재 라운드 종료 시, 제한 시간은 다음 턴부터, 확률은 다음 손패 보충부터 반영한다. 현재 턴·손패를 초기화하지 않는다. 다른 규칙은 대기 중에 변경하며 대기실에서 규칙을 바꾸면 사람의 참여를 초기화한다.

개발자 설정은 Debug 실행에 `-- --developer`를 추가한 **로컬 서버 방장**에게만 열린다. 카드별 추첨 포함/제외·가중치, 병 스턴·회수 대기를 조절한다. 기본 카드 정의를 새로 작성하는 에디터는 아니며 기존 카탈로그를 추첨 목록에 넣고 빼는 기능이다. UI 외에도 서버가 실제 발신자를 검사한다. 기존 빠른 예시 경기는 `-- --developer --quick-test`로 명시적으로 실행한다. 그 경로의 F1~F4 디버그 도구는 유지한다.

## 카드와 한 판

각자 7장까지 쓴 만큼 보충 → 5초 동안 받은 카드 확인 → 자리 순서대로 각자 다트 3발 → 다음 라운드 전 테이블 집합 → 반복 → 공동 순위. 혼자 연습도 같은 흐름이다. 따로 카드 턴은 없다(2026-10-31).

다트 턴(조준·비행) 동안 누구나 어떤 카드든 쓸 수 있고, 효과는 누가 쓰든 **지금 던지는 사람**에게 쓰는 순간 걸린다. 장수 제한은 없고 겹치면 전부 적용된다. 무효 ×0만 카드를 꺼내 든 사람을 Tab으로 골라 막는다. 꺼내 든 카드는 1.2초 후 사용할 수 있다. 날아가는 다트에 쓰면 점수·과녁 카드는 꽂히는 순간 계산에, 궤적 카드(무거운 다트·바람·특수 다트·힘 증가)는 꽂히는 자리를 바꿔 반영한다. 봇도 다트 턴마다 60% 확률로 한 장을 쓴다(자기 차례 = 나에게 좋은 카드, 남의 차례 = 방해 카드, 자기 차례에 남이 꺼낸 카드는 가진 무효로 막는다). 카드 턴 시간 설정은 없앴다. 카드 계산은 기존 `game/card_round/rules/round_rules.gd`를 재사용하며 방장이 확정한다. 최근 효과와 적중은 우측 최대 5줄 로그로 표시한다. 목표 점수는 도달 시 종료, 카운트다운은 정확히 0이면 승리하고 초과하면 차례 시작 점수로 돌아간다. 라운드 상한에 도달하면 카운트다운은 낮은 점수가 우선한다.

라운드 사이 테이블 집합은 기존 10초 규칙을 유지한다. 늦으면 자동 착석과 다음 라운드 이동 속도 50%가 적용된다. 세부 시연값은 팀 논의로 조정한다.

## 공간과 소품

기존 ㄱ자 펍의 원형 테이블·캐릭터·과녁을 그대로 쓴다. 원형 상판/충돌은 같은 배치 원본을 사용한다. 배치를 바꾸면 `art/pub/pub_builder.gd`로 생성한다. 생성된 씬을 직접 수정하지 않는다.

**네온 오락실 테마(기본, 2026-10-30)**: 펍 그림에서 바·당구대·NPC 구석·술통을 빼고(`TableView.rebuild_pub`) 블랙라이트 카펫·네온·경품 진열대·오락기 5대와 함께 인형뽑기·가챠 2대·농구 오락기를 세운다(`game/lounge/arcade/`). 뽑은 인형을 던지면 맞은 사람 얼굴이 잠깐 가려지고, 가챠 캡슐은 던져 맞히면 상대에게·직접 열면 나에게 효과(왕머리·먹물·어질·색종이·꽝)가 난다. 농구 오락기는 30초 HOOP FEVER(2점, 3 m 밖 3점). 남이 하는 기계는 E 로 흔들어 방해할 수 있다.

**깨지는 소품**: 병·큐대는 8 m/s 이상으로 부딪히거나, 1.7 m 이상에서 떨어지거나, 5 m 이상 날아가거나, 파워 카드로 던지면 깨지고 6초 뒤 제자리에 새것이 생긴다. 손 높이에서 툭 놓으면 안 깨지고 눕는다(수치는 `game/lounge/lounge_world.gd` 상수, 밸런스 초안).

병은 가까이서 잡아 마시거나 던진다(펍 테마에만 큐대가 나온다). 음주가 켜진 방에서만 숨겨진 취기가 쌓이고 서서히 줄어든다. 화면 기울기·흐림으로 표시하며 수치 스택은 HUD에 공개하지 않는다. 캐주얼은 SODA로 표시하며 취기가 없다. 병의 기본 투척은 짧고 무겁고, 힘 카드가 적용되면 멀리 날아간다. 맞은 사람은 기본 1초 스턴. 임시 밸런스로 빗나감 회수 대기 2초, 적중은 여기에 스턴 시간을 더한다. 점수 벌점은 팀 미확정이다. 당구공·큐는 운반·내려놓기만 가능하다. 소품을 끄면 들고 있거나 날아가던 물체도 내려놓는다.

주크박스는 독립된 전원·볼륨·링크 버튼으로 모두가 간섭할 수 있다. 링크가 없을 때는 자체 생성 짧은 음악 루프를 재생한다. YouTube는 **외부 브라우저의 공식 IFrame 플레이어**를 사용한다. 각 참가자가 B로 열어 한 번 재생을 허용해야 한다. 영상 ID·전원·볼륨을 공유하며 재생 위치까지 정확히 맞추지는 않는다. Godot 내장 WebView/오디오 추출 방식은 아니다. 로컬 브리지는 `127.0.0.1`에만 열고 게임 종료 시 닫힌다.

python tests/run_lounge.py --godot $godot
python tests/run_deck_show_remote.py --godot $godot
& $godot --headless --path . --script res://tests/test_rules.gd

& $godot --headless --path . --script res://tests/test_lounge.gd
